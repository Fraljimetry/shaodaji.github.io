User guide使用指南

Construct accurate geometry, communicate mathematics through diagrams, and explore 2D/3D graphs.

精确构造几何图形、绘制数学图示并探索二维与三维函数图像。

1. Get started1. 开始使用

  1. Choose a Geometry or Diagram tool, or select a plotting mode beside the expression box.
  2. Click on the canvas as prompted, or enter an expression and press Enter.
  3. Select an object with Move to change its Properties. Use the Objects list to locate, hide, lock, reorder or delete it.
  4. Save JSON regularly. Use Export for SVG, PNG, WebP or JPEG output.

Create a point with P and select it with V. Save the editable JSON before exporting an image.

  1. 从几何、交换图工具中选择构造，或在表达式框旁选择绘图模式。
  2. 按工具提示点击画布，或输入表达式并按 Enter。
  3. 使用移动工具选择对象，在属性面板中编辑；在对象列表中搜索、隐藏、锁定、排序、删除。
  4. 定期保存 JSON；使用导出获得 SVG、PNG、WebP、JPEG。

按 P 放置点，按 V 切换至移动工具；导出图片前请先保存可编辑 JSON。

2. Workspace & selection2. 工作区与选择

  • Objects lists items in drawing order. Drag the reorder grip, or focus it and use Alt+↑/↓. Search by object name; click a row to select it.
  • Properties edits the selected item. Expand or collapse the panel with ±. Changes to numeric fields normally commit on Enter or when focus leaves the field; invalid values are rejected rather than applied.
  • Tools contains collapsible Geometry and Diagram groups. A collapsed group only hides its tools, not its objects.
  • Move selects and edits; Pan moves the view. Escape cancels an incomplete action. Undo/Redo recover ordinary changes.
  • Desktop panel dividers are draggable. On narrow screens, side panels open as drawers; tap outside or press Escape to dismiss them.
  • Change interface language in the top bar. Interface theme and canvas Background are separate: changing the theme does not recolor objects.

Use V for Move and H for Pan. On hover, Selection preview predicts the geometric target; compatible point targets have priority at overlaps. Alt-drag pans the view; Escape cancels an in-progress construction.

左侧对象列表支持拖动排序（键盘 Alt+↑/↓），属性面板编辑当前对象；右侧工具分组可折叠。移动用于选择，平移用于移动视野。Escape 可取消正在进行的操作；撤销／重做可恢复修改。桌面端拖动分隔线改变面板尺寸；窄屏点击外部或按 Escape 关闭侧栏。语言、主题和画布背景可独立设置。数学标签默认 LaTeX，逐字文字可在属性中选择纯文本。

V 是移动，H 是平移。开启“选择预览”后，悬停显示即将选中的几何对象；相交位置优先选择与工具兼容的点。Alt 拖动可平移视图；Escape 取消未完成的构造。

3. Geometry & constructions3. 几何构造

Use Geometry groups for points, lines and vectors, circles and conics, polygons, intersections, transformations, and curves and loci. Follow the tool's point/object prompts in order; derived objects generally update when their parents move.

Use Diagram node and Morphism for commutative diagrams. New mathematical labels default to LaTeX; select Plain text in Properties when you want literal text. Move diagram labels by dragging the displayed label. Choose arrow route, line style, label side and spacing in Properties. Crowded diagrams may require manual adjustment.

Draw free curves and shapes

Select Free curve. Before drawing, its Properties let you choose Shape: Free, Ellipse or Polygon. Drag a continuous stroke on the canvas; an ellipse or polygon is closed automatically. Regular is on by default: an ellipse becomes a circle, and a polygon becomes a regular triangle, square or other regular polygon based on the corners in your gesture. Turn Regular off for an oval, rectangle or irregular polygon. The original gesture is retained if you change the options later.

Free strokes support the full line and arrowhead controls. For Ellipse and Polygon, only Solid, Dashed and Dotted lines are available; arrowheads are disabled. Shape/Regular share one row of Properties; Line style/Arrowheads share the next. A very small or unclear gesture may be rejected. These shapes can be used with compatible Geometry tools: regular hand-drawn ellipses act as circles for tangents, intersections and points on circles; other ellipses and polygons participate in curve intersections and points on their outline. The shape is still based on your drawn gesture, not a set of draggable native construction anchors.

For a dependent construction, edit a parent and observe descendants before saving. A tool requiring a circle will not accept a line even if the line is drawn above it.

几何工具包含点线、圆和圆锥曲线、多边形、交点、变换、轨迹等。按提示依次选择构造点或对象；派生对象通常随原对象移动。交换图先放置节点，再用态射连接；属性中可调箭头、标签位置与线型，密集图示仍可能需要手动调整。

对于依赖构造，可移动原始对象并观察派生对象，再保存。需要圆的工具不会将重叠直线当成圆。

自由曲线与手绘形状

选择自由曲线工具。绘制前可在属性中选择形状：自由、椭圆或多边形；按住鼠标在画布上描出轮廓即可。规则形状默认勾选：椭圆转成圆，多边形按手势拐角数整理为正三角形、正方形或其他正多边形。取消勾选后可绘制椭圆、矩形或不规则多边形。原始笔迹会保留，因此之后仍可更改形状和规则程度。

自由曲线可用完整线型和箭头选项；椭圆、多边形仅允许实线／虚线／点线，不支持箭头。属性中的形状与规则形状并排，线型与箭头并排。轮廓过小或不清楚时可能无法生成形状。这些形状可与兼容的几何工具交互：规则椭圆可按圆参与切线、交点与圆上点构造；其他椭圆和多边形可参与曲线求交及轮廓上的点构造。但形状仍由手势生成，并不是具有可拖动原生构造顶点的几何对象。

可输入 sin(pi*x)、phi^2-phi-1、x^2+y^2=4。绘图输入是数值表达式，而非 TeX 指令。

Sliders and algebra definitions

Choose Slider beside Move and Pan, then click the 2D canvas to place a control. Drag its blue handle to change the value. Use the Objects panel’s algebra input (the </> icon) and press Enter to create constructions. Edit slider settings in Properties; use the Objects three-dot menu for Show/Hide, Lock, and Delete.

Enter these definitions one line at a time:

a = Slider(1, 5, 0.1, 2)
A = (a*cos(pi/3), a*sin(pi/3))
B = (0, 0)
Segment(A,B)

Dragging a updates A and the dependent segment. Select A in Objects to edit its X/Y expressions in Properties. Formula-backed points cannot be dragged independently: change their formula or slider instead. Undo/redo and project JSON retain the expressions. A slider cannot be deleted while a point expression requires it.

Additional live 2D commands:

C = (a, a)
FixedLength(A,B,a)
FixedAngle(A,B,pi/a)
Rotate(B,A,a/2)
Dilate(B,A,a)
Triangle(A,B,C)
ClosedSpline(A,B,C)

Length, fixed-angle (in radians), rotation and dilation values can reference sliders. Select the resulting object in Objects to edit its measurement formula in Properties. Vector, Ray, CircleThrough3, Triangle, Quadrilateral, Spline, ClosedSpline, CircularArc, Hyperbola, and other named-point constructions use the same dynamic references. A command that needs a line or circle reference cannot be replaced by a point-only constructor.

Current scope: 2D only. Invalid or out-of-range slider values are rejected rather than silently breaking dependent geometry. Arbitrary scripting, parameterization of every geometry property, variable polygon side counts, and live 3D plot parameters are not yet implemented. Slider handles are editor controls, excluded from image exports.

滑块与代数定义

在“移动”和“平移”旁选择滑块，点击二维画布放置控件，拖动蓝色圆点改变数值。左侧代数标签可调整滑块范围、隐藏或显示画布控件，以及输入公式构造；原有对象标签和属性面板仍可使用。

逐行输入：

a = Slider(1, 5, 0.1, 2)
A = (a*cos(pi/3), a*sin(pi/3))
B = (0, 0)
Segment(A,B)

拖动 a 会更新 A 以及依赖它的线段。可在对象属性中编辑 A 的 X/Y 表达式。公式点不能直接拖动，应修改公式或滑块。撤销、重做和 JSON 保存均保留公式；有依赖时不能删除滑块。

新增二维参数构造示例：

C = (a, a)
FixedLength(A,B,a)
FixedAngle(A,B,pi/a)
Rotate(B,A,a/2)
Dilate(B,A,a)
Triangle(A,B,C)
ClosedSpline(A,B,C)

长度、固定角（弧度）、旋转和缩放都可使用滑块公式。在对象属性中可修改其数值表达式。向量、射线、三点圆、三角形、四边形、样条、闭合样条、圆弧、双曲线等命名点构造可保持动态依赖。需要直线或圆作为输入的命令不能直接用点取代。

当前范围：仅二维。非法或越界公式会被拒绝，避免破坏现有构造。不支持任意脚本、所有几何属性参数化、滑块控制多边形边数或三维图形联动。导出图像不包含滑块编辑控件。

Properties → Expression: The Name field is separate. Expressions show only the definition, such as Circle(A, B) rather than C = Circle(A, B). Edit the definition here and rename objects using Name. Existing named definitions are still accepted for compatibility.

属性 → 表达式：名称是独立字段。表达式仅显示定义，例如 Circle(A, B)，不显示 C = Circle(A, B)。在此编辑定义，在“名称”字段中重命名；为兼容旧输入，仍接受带名称的定义。

4. Expressions & supported functions4. 数学表达式与函数

Plotting expressions are numerical formulas, not JavaScript and not LaTeX. Use +, -, *, /, ^ and parentheses. Function calls require parentheses, for example max(x,0). Use commas to separate arguments. Constants pi, e and phi (golden ratio, also φ) work in real and complex plots; i works in complex plots only. Names are case-insensitive. Multiplication may be implicit: 2pi, 3x, 2sin(x), (x+1)(x-1). Write 1/(2*x) when grouping matters.

Real-valued functions (2D and 3D)

All the functions below are actually implemented for real expressions. Angle inputs and outputs use radians.

Complex-valued functions (domain coloring and 3D complex plots)

Complex expressions use z and imaginary unit i. The supported functions are:

Examples: z^3-1, sin(z), log(z), conj(z), re(z), abs(z), pow(z,2), norm(z). re, im, abs, arg and norm return real numbers (represented as complex numbers with zero imaginary part). norm(z)=re(z)^2+im(z)^2. arg(z) is in radians (−π to π). Roots, powers, logarithms and inverses use principal branches; branch cuts and poles can create visible discontinuities. pow requires two arguments; all other complex functions require one. Real-only functions such as min, max, floor, ceil, round, mod and atan2 are not supported for complex inputs.

Try sin(pi*x), phi^2-phi-1, and x^2+y^2=4. Plot formulas are numeric expressions, not TeX commands.

表达式使用数值计算语法，不是 JavaScript 或 LaTeX。支持 + - * / ^、括号和省略乘号，例如 2pi、3x、2sin(x)、(x+1)(x-1)。函数必须带括号，多个参数以逗号隔开。常数 pi、e、phi（黄金比例，也可写 φ） 适用于实数和复数；i 仅用于复数。名称大小写不敏感。角度以弧度计算。

2D Algebra input — exact command reference二维代数输入——命令完整参考

In the Objects sidebar, the </> icon indicates Algebra input (default). Type one definition and press Enter; there is no Add button. Click the icon once to switch to Find (magnifier), and again to return to Algebra. All successful constructions are ordinary Objects with the same Properties, drag ordering, locks, dependency propagation, undo/redo and Recently Deleted controls. Clicking an object opens its Properties. Algebra is limited to the 2D workspace.

Sliders, coordinates, animation

a = Slider(0, 10)
b = Slider(-3, 3, 0.1, 1)
t = Slider(0, 2*pi, 0.01, 0, 1, oscillatory)
A = (a*cos(t), b*sin(t))
B = (clamp(a, 1, 6), mod(-5, 3))

Slider(min, max[, step[, value[, speed[, mode]]]]). With five arguments, the fifth may be a speed or the mode. Modes: periodic, oscillatory, once. Speed is 0.05–10 cycles/s. Use the Play/Pause control in the Objects row, and the range, speed, mode, appearance and value track in Properties. Drag the control background in Move/Pan to reposition it; if Snap to Grid is enabled its position snaps, not its numeric value. Sliders and parameterized point expressions retain their formulas when saved.

PerpendicularBisector(A,B) is an alias. Polygon, Polyline and Spline accept variable point counts (minimums enforced by the application); Bezier requires exactly four. Circle takes a center and a point on the circle—not a radius expression. Ellipse uses two foci and a point. Geometry-dependent constructions: Parallel(A,s), Perpendicular(A,s), Foot(A,s) and Intersect(s,t); the latter currently supports intersecting straight objects.

f = FixedLength(A,B,a)
g = FixedAngle(A,B,rad(60))
r = Rotate(B,A,t)
d = Dilate(B,A,a)
p = RegularPolygon(A,B,2^3)
N = Node(1+cos(pi), sqrt(9), "N")
M = Node(3, 4, "M")
Morphism(N,M,"f")
f(x) = sin(x)+x^2

FixedLength/FixedAngle and transformations reference existing objects; angles are in radians. RegularPolygon uses a center, a vertex and a constant integer expression yielding 3–100 sides. Its side count is not currently reactive to sliders. Node coordinates accept constant arithmetic expressions; Node coordinates are not slider-reactive. The function-definition form is for a plotted function, not a user-defined callable arithmetic helper.

Arithmetic allowed in slider expressions and coordinates

Operators + - * / ^; constants pi, π, e, phi, φ, ϕ; common functions sin cos tan asin acos atan atan2 sqrt cbrt abs exp ln log log10 log2 floor ceil round trunc sign min max pow hypot; hyperbolic functions sinh cosh tanh asinh acosh atanh; and clamp(x, low, high), mod(x, y), rad(degrees), deg(radians). The mod helper returns a nonnegative remainder for a nonzero divisor. Multiplication is explicit (2*pi). Nested calls such as clamp(min(a,8),0,5) are supported. Input is numerical, with finite-value and argument-count validation; invalid input leaves the existing project intact.

Not supported: arbitrary scripting, loops, conditional statements, custom callable functions, symbolic algebra, dynamic polygon side count, general expression bindings for all object properties, or 3D Algebra. If a construction is rejected, check that referenced object names exist and that their types match the command.

在“对象”侧栏中，</> 表示代数输入（默认）。每行输入一个定义并按 Enter 提交，不再有添加按钮。单击图标切换为放大镜“查找”，再次单击返回代数输入。代数创建的对象与鼠标创建的对象共用属性、拖动排序、锁定及其后代依赖、撤销/重做和最近删除。选中对象即可在属性中编辑。本功能仅限二维。

滑块、坐标和动画

a = Slider(0, 10)
b = Slider(-3, 3, 0.1, 1)
t = Slider(0, 2*pi, 0.01, 0, 1, oscillatory)
A = (a*cos(t), b*sin(t))
B = (clamp(a, 1, 6), mod(-5, 3))

语法：Slider(min, max[, step[, value[, speed[, mode]]]])。第五项可为播放速度或模式；模式有 periodic（周期）、oscillatory（往返）和 once（单次），速度为 0.05–10 周期/秒。对象行中的按钮控制播放/暂停；范围、播放模式、速度、颜色和滑动条在属性中编辑。移动/平移工具可拖动滑块背景改变画布位置；网格吸附只影响位置，不影响数值。存档保留公式。

PerpendicularBisector 是别名。多边形、折线和样条支持变长的点引用（有最少点数限制），贝塞尔曲线必须有四个控制点。Circle(A,B) 为圆心和圆上点，不接受直接半径表达式。椭圆为两焦点加一点。依赖构造包括 Parallel(A,s)、Perpendicular(A,s)、Foot(A,s) 和 Intersect(s,t)（目前只支持相交的直线对象）。

g = FixedAngle(A,B,rad(60))
r = Rotate(B,A,t)
d = Dilate(B,A,a)
p = RegularPolygon(A,B,2^3)
N = Node(1+cos(pi), sqrt(9), "N")
M = Node(3, 4, "M")

固定长度、角度和变换可依赖滑块；角度单位为弧度。正多边形需要圆心、顶点及结果为 3–100 的常量整数表达式，边数目前不随滑块变化。Node 的坐标支持常量算式，但不随滑块动态更新。f(x) 用于绘图，不是自定义可调用数学函数。

支持的数值函数

运算符 + - * / ^；常数 pi, π, e, phi, φ, ϕ；函数 sin cos tan asin acos atan atan2 sqrt cbrt abs exp ln log log10 log2 floor ceil round trunc sign min max pow hypot sinh cosh tanh asinh acosh atanh clamp mod rad deg。clamp(x,low,high) 为限幅，mod(x,y) 为非负余数（除数不能为零），rad／deg 转换角度单位。支持嵌套调用，乘法需明确写作 2*pi；对参数个数和非有限结果进行检查，无效提交不改变已有对象。

不支持任意脚本、循环、条件语句、自定义可调用函数、符号运算、动态多边形边数、所有对象属性的通用公式绑定或三维代数输入。构造失败时，请检查引用对象是否存在、名称和类型是否正确。

5. 2D plotting workflows5. 二维绘图

  • Function: one real expression in x, e.g. max(0,sin(x)).
  • Parametric: two real expressions using t in the Construction input, e.g. 2cos(t) and 2sin(t). Previously saved legacy curves using u/v are handled separately for compatibility.
  • Implicit: a real equation in x,y, e.g. x^2+y^2=4; without =, the expression is set to zero.
  • Vector field: real components X(x,y) and Y(x,y), e.g. -y and x.
  • Domain coloring: one complex expression in z, e.g. z^2+1. The colored background sits behind the grid and axes.
  • 3D plotting: use the dedicated 3D workspace for real surfaces, implicit surfaces, vector fields and supported complex domain-coloring views. Choose mesh/detail and color controls in 3D Settings.

Polar parametric plots and geometric interaction

After adding a Parametric curve, select it in Objects and enable Use polar coordinates in Properties (off by default). Enter r(t) (for example 2 or 1+cos(t)) and adjust t min/t max. The displayed point is (r(t)cos(t), r(t)sin(t)) and angles use radians. Uncheck the option to return to the original x(t) and y(t) expressions without losing them.

Some unmistakable plotted forms can also be selected as ordinary geometric lines or circles for compatible constructions such as intersections, constrained points, tangents and transformations: affine functions 2x+3, linear implicit equations x+y=1, polynomial circles (x-2)^2+(y+1)^2=9, straight parametric paths x(t)=t/y(t)=2t, complete sine/cosine circles and constant-radius full-turn polar plots. A bounded parametric straight path behaves as a segment, not an infinite line. Only recognized algebraic forms qualify; a curve that merely looks straight or circular, partial arcs, and general conics retain ordinary curve behavior. Constructions cannot infer geometry from pixels alone.

For vector fields, enter two components and use Density and Normalize lengths in Properties. For implicit contours, an even-multiplicity zero may be missed by finite-resolution contour extraction.

  • 函数：以 x 为自变量，例如 max(0,sin(x))。
  • 参数曲线：在构造输入框中，两条实数表达式均使用参数 t，例如 2cos(t) 与 2sin(t)；既有项目中使用 u/v 的旧曲线仍按兼容规则读取。
  • 隐式：以 x,y 为变量，输入 x^2+y^2=4；未写等号时以零为等值线。
  • 向量场：两个实数分量，例如 -y、x。
  • 定义域着色：以 z 为变量，例如 z^2+1，颜色绘制在网格与坐标轴下方。
  • 三维：使用独立三维工作区构造曲面、隐式图、向量场及支持的复数着色视图。

极坐标参数绘图与几何识别

创建参数曲线后，在对象列表中选中它，再到属性中勾选使用极坐标（默认关闭）。输入 r(t)，如 2 或 1+cos(t)；t min/t max 控制参数区间。实际绘图坐标是 (r(t)cos(t), r(t)sin(t))，角度单位为弧度。取消勾选即可恢复原有 x(t)/y(t)，不会丢失原表达式。

在代数形式能直接确认时，部分绘图可以作为真正的直线或圆参与交点、约束点、切线和变换等几何操作。支持简单仿射函数 2x+3、线性隐式方程 x+y=1、圆方程 (x-2)^2+(y+1)^2=9、线性参数路径、完整周期的正弦／余弦圆及常半径完整极坐标圆。有限参数区间中的线性路径是线段，不是无限直线。仅凭图像看起来像直线或圆并不足以认定；部分圆弧、一般圆锥曲线和无法严格识别的表达式仍按普通曲线处理。

向量场需要两个分量，密度与“归一化长度”在属性中设置。隐式曲线存在偶重零点时，有限分辨率的等值线算法可能漏画。

Editable construction expressions可编辑的几何构造表达式

The Objects list displays names only, without subtitles. Select a 2D point, plotted function, or supported geometric construction to see its Expression in Properties. The Expression field appears immediately after Name and before Label format and Label; it edits the same object rather than creating a duplicate. For example, A = (1,2), f(x) = sin(x) and Segment 4 = Segment(A,B). Changing a referenced object's Name automatically updates the displayed expression because dependencies are stored by stable IDs. Edit the object name separately in Name. Invalid edits are rejected by the geometry validator.

Properties supports editable semantic constructors for constrained points, intersections and branches, transforms, triangle centers, regular polygons, loci, Bézier/spline curves, 2D plot definitions, diagram objects and ordinary geometry. Examples: P = PointOnObject(Line1, parameter=0.5), C = TriangleCenter(A,B,D,centerKind="centroid"), T = Rotate(A,B,amount=1.57). Option values are JSON numbers or quoted strings. These extended constructors are editable in Properties; not every one is accepted by the shorter Construction input command language. Freehand paths are not algebraic. Owned sides display Side(parent,index) but must be edited through their parent. Changing vertex count or derived-edge structure is restricted; invalid or cyclic edits leave the geometry unchanged. 3D remains governed by its own plotting editors.

对象列表仅显示名称，不再显示副标题。选择二维点、函数或支持的几何构造，可在属性中紧接“名称”、位于“标签格式”和“标签”之前看到表达式，并直接修改原对象而非创建副本，例如 A = (1,2)、f(x) = sin(x)、Segment 4 = Segment(A,B)。依赖关系使用稳定对象 ID，因此引用对象重命名后，表达式中的名称会自动更新。对象自身的名称请在“名称”字段修改。无效修改会被几何校验拒绝。

属性面板支持约束点、各类交点和分支、几何变换、三角形中心、正多边形、轨迹、贝塞尔与样条、二维绘图定义和交换图等语义表达式。例如 P = PointOnObject(Line1, parameter=0.5)、C = TriangleCenter(A,B,D,centerKind="centroid")、T = Rotate(A,B,amount=1.57)。选项为 JSON 数值或带双引号的字符串。这些扩展语法可在属性中编辑，但较简短的“构造输入”命令不一定支持。手绘路径不能代数化；派生边显示只读的 Side(父对象,序号)，须通过父对象修改。涉及顶点数量或派生边结构的变更受到限制；非法或循环依赖修改会拒绝且不改变对象。三维仍使用独立绘图编辑器。

Input completion (2D and 3D)输入补全（二维和三维）

Sliders also have an editable Expression directly below Name in Properties. For example, Slider(0, 10, 0.1, 5, 1, periodic) specifies minimum, maximum, step, current value, playback speed, and playback mode. Edit it to change those settings atomically; range controls, slider dragging, and playback refresh the displayed Expression. The slider name is edited separately. Invalid ranges or modes are rejected without changing the slider.

The Algebra field and the Construction input fields provide contextual function and example suggestions. Type a function prefix (such as si or sq) to see matching names. Click a suggestion or use the up/down arrows and Tab to insert it; the cursor is placed between automatically supplied parentheses. Enter still submits the input, without silently accepting a guess. Press Escape to dismiss the menu. Typing ( or [ inserts the matching closing bracket; typing a closing bracket over an existing matching one advances the cursor. Backspace between an empty bracket pair removes both. Argument hints highlight the current parameter in supported calls (for example Slider(minimum, maximum, step, value)), and a mismatched closing bracket shows a non-blocking error. Press Ctrl+Space to reopen completions. Hints do not evaluate or submit expressions.

Suggestions are limited to functions accepted by the selected real or complex parser; for example, sec(x) is available in real plotting and conj(z) in complex domain coloring, but rad(x) is Algebra-only. Commas inside nested brackets or quoted labels do not shift argument hints. Variable suggestions follow the selected plot mode: two-dimensional parametric input uses t, and three-dimensional parametric surfaces use u/v. The popup uses the same font and width as its expression field, including on narrow screens. Suggestions reflect whether Construction input is in 2D or 3D and the selected plot mode. They are only typing aids: accepting a suggestion does not alter the document until the normal submission, and the existing mathematical parser remains authoritative. Example suggestions cover supported plot input patterns; they do not add new plotting commands or make the 3D Algebra sidebar programmable.

滑块在属性面板的名称下方也提供可编辑的表达式（Expression）。例如 Slider(0, 10, 0.1, 5, 1, periodic) 依次表示最小值、最大值、步长、当前值、播放速度和播放模式。修改该表达式可原子更新滑块配置；数值控件、拖动和播放也会同步更新所显示的表达式。名称单独编辑；无效范围和模式不会修改滑块。

代数输入与构造输入均提供按上下文筛选的函数及示例建议。输入函数前缀（如 si、sq）即可显示候选；可点击候选，或使用上下箭头与 Tab 插入，光标会置于自动补齐的括号之间。Enter 仍用于正常提交，不会擅自接受猜测；Escape 关闭候选框。输入 ( 或 [ 时会自动补齐右括号；光标位于一对空括号之间时按退格可同时删除两侧括号。支持的函数与构造命令会提示当前参数（例如 Slider(minimum, maximum, step, value)）；右括号不匹配时显示非阻断式提示。可按 Ctrl+Space 重新显示补全候选。提示不会自动执行表达式。

补全候选依实际解析器区分实数、复数和二维代数函数：例如实数绘图支持 sec(x)，复数着色支持 conj(z)，但 rad(x) 仅供代数使用。嵌套括号和引号内的逗号不会误计参数位置。变量补全按绘图模式提供：二维参数输入使用 t，三维参数曲面使用 u/v。候选下拉框与对应表达式输入框保持一致的字体字号和宽度，窄屏也适用。构造输入的建议随二维／三维模式及绘图类型而改变。建议只辅助输入；选中候选不会立即改变文档，最终仍由现有数学解析器验证。三维仅提供绘图表达式补全，不表示三维对象可以通过侧栏代数定义。

6. 3D visualization6. 三维可视化

In 3D Interface, enable Fix region to keep the current shared plotting bounds while adding or editing graphs. You can still orbit and zoom. Editing a plot's drawing region updates the fixed region; turn Fix region off to fit all visible graphs automatically.

在三维界面中勾选固定绘图范围，即可在添加或修改多个图形时保持当前共同显示范围。仍可旋转和缩放。手动修改图形范围会更新锁定的范围；取消勾选则恢复自动适应可见图形。

Enable 3D plotting mode in Interface. Pick Function surface, Parametric surface, Implicit surface, Vector field or Domain coloring. Set ranges and Mesh detail according to the mode. Drag to orbit and scroll to zoom; adjust Projection, View yaw/pitch, Lighting and Reference cube in 3D settings.

Use z=sin(x)*cos(y) or the mode’s supported function input; an implicit example is x^2+y^2+z^2=4. The sampler is numerical: discontinuities, genuine holes, or insufficient mesh detail can change the rendered result. Complex 3D coloring uses modulus/argument conventions and may differ from simple surface height plots.

More mesh detail costs computation and memory. Compare a suspicious hole at two mesh resolutions; a mathematical opening should not be indiscriminately filled. Save the JSON to reproduce camera, region and colors.

在“界面”中开启三维绘图模式，选择函数曲面、参数曲面、隐式曲面、向量场或定义域着色。按模式设置范围和网格精度。拖动旋转、滚轮缩放；可在三维设置中调整投影、视角、光照和参考立方体。

例如在相应绘图模式输入 sin(x)*cos(y)，或使用隐式方程 x^2+y^2+z^2=4。绘制基于数值采样：不连续点、真实开口或网格过粗均可能影响显示；复数三维着色还涉及模长与辐角规则。

网格越精细，耗时和内存可能越多。怀疑出现孔洞时，可对比两种网格精度；不要擅自填补数学上真实存在的开口。保存 JSON 以复现相机、范围与色彩设置。

7. Settings, saving & export7. 设置、保存与导出

Use Settings for background, guides, snapping, plot detail and evaluation limits, label and interaction preferences, theme, and 3D options. High resolution or many simultaneous plots may slow rendering; an undefined expression (such as 1/0) can leave gaps. Not every expression has a finite real value.

Save produces editable JSON. Export produces SVG or raster images (PNG, WebP, JPEG), with controls for crop, scale, guides and transparency. JPEG cannot retain transparency. Semantic tikz-cd export supports diagram nodes and morphisms. It now uses the diagram’s node spacing to produce roomier LaTeX layouts and exports label positions along arrows and manual X/Y shifts. Since tikz-cd uses a grid, uneven spacing and curved paths may still differ from the canvas; compile and inspect the result. Keep JSON for exact future editing.

Background sets the color used by the canvas/export; Transparent removes the opaque background from supported image formats, not object opacity. The editing grid and axes do not become part of exports.

设置可控制网格、吸附、背景、绘图精度、计算预算、标签和三维外观。大量对象或高分辨率会降低速度；极点和无定义值可能造成曲线断裂。保存导出的是可编辑 JSON，图片导出可选择裁切、比例和辅助线。JPEG 不支持透明背景；tikz-cd 仅支持交换图节点和态射，导出时会按画布节点间距设定行列间隔，并保留标签沿箭头的位置及手动水平、垂直位移。由于 tikz-cd 使用网格，非均匀节点间隔、曲线形状与标签效果可能与画布不同；请编译检查，并保留 JSON 用于继续编辑。

表达式不能包含脚本、用户自定义函数、条件语句、数组、符号求导／积分、求和语法或 LaTeX 命令。有限采样并不能保证捕捉所有细节或奇点。

“背景”设置画布/导出背景色；“透明”在支持的图片格式中去除不透明背景，并不改变对象本身的不透明度。编辑用网格和坐标轴不随图像导出。

9. Limitations & troubleshooting9. 限制与排错

The formula parser does not execute arbitrary scripts, custom function definitions, conditionals, arrays, summation or integration syntax, symbolic differentiation, or LaTeX commands. A comma is valid only within a supported multi-argument function call. Inputs are evaluated numerically and sampled at finite resolution. If a curve or surface looks incomplete, inspect its domain, singularities and sampling settings.

If an export looks different, check unsupported object types, geometric dependency, sampling resolution, view bounds and line/label visibility. Keep JSON for reliable editing.

绘图表达式不支持任意代码、数组、用户函数、符号积分或直接的 LaTeX 指令。所有曲线和曲面均为有限采样；参数区间、数学奇点和采样精度会影响结果。几何识别只适用于可以明确判断的直线和圆。

导出外观异常时，请检查对象类型支持情况、几何依赖、采样精度、视野边界及线条/标签可见性。需要继续编辑时请保留 JSON。
