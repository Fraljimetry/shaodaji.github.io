MathIllustrator — User Guide

Create geometric constructions, mathematical diagrams and 2D/3D plots in your browser. Save a JSON project to continue editing it later; exported images are for presentation, not editable backups.

Getting started

  1. Choose a Geometry or Diagram tool, or select a plotting mode beside the expression box.
  2. Click on the canvas as prompted, or enter an expression and press Enter.
  3. Select an object with Move to change its Properties. Use the Objects list to locate, hide, lock, reorder or delete it.
  4. Save JSON regularly. Use Export for SVG, PNG, WebP or JPEG output.

Workspace and controls

  • Objects lists items in drawing order. Drag the reorder grip, or focus it and use Alt+↑/↓. Search by object name; click a row to select it.
  • Properties edits the selected item. Expand or collapse the panel with ±. Changes to numeric fields normally commit on Enter or when focus leaves the field; invalid values are rejected rather than applied.
  • Tools contains collapsible Geometry and Diagram groups. A collapsed group only hides its tools, not its objects.
  • Move selects and edits; Pan moves the view. Escape cancels an incomplete action. Undo/Redo recover ordinary changes.
  • Desktop panel dividers are draggable. On narrow screens, side panels open as drawers; tap outside or press Escape to dismiss them.
  • Change interface language in the top bar. Interface theme and canvas Background are separate: changing the theme does not recolor objects.

Geometry and diagrams

Use Geometry groups for points, lines and vectors, circles and conics, polygons, intersections, transformations, and curves and loci. Follow the tool's point/object prompts in order; derived objects generally update when their parents move.

Use Diagram node and Morphism for commutative diagrams. New mathematical labels default to LaTeX; select Plain text in Properties when you want literal text. Move diagram labels by dragging the displayed label. Choose arrow route, line style, label side and spacing in Properties. Crowded diagrams may require manual adjustment.

Plotting expressions — syntax

Plotting expressions are numerical formulas, not JavaScript and not LaTeX. Use +, -, *, /, ^ and parentheses. Function calls require parentheses, for example max(x,0). Use commas to separate arguments. Constants pi and e work in real and complex plots; i works in complex plots only. Names are case-insensitive. Multiplication may be implicit: 2pi, 3x, 2sin(x), (x+1)(x-1). Write 1/(2*x) when grouping matters.

Complex-valued functions (domain coloring and 3D complex plots)

Complex expressions use z and imaginary unit i. The supported functions are:

CategorySupported functions
Elementarysin cos tan sec csc cot sinh cosh tanh
Inverseasin acos atan asinh acosh atanh
Exponential / roots / logsexp expm1 sqrt cbrt log ln log10 log2 log1p pow
Componentsre im conj abs arg norm sign

Examples: z^3-1, sin(z), log(z), conj(z), re(z), abs(z), pow(z,2), norm(z). re, im, abs, arg and norm return real numbers (represented as complex numbers with zero imaginary part). norm(z)=re(z)^2+im(z)^2. arg(z) is in radians (−π to π). Roots, powers, logarithms and inverses use principal branches; branch cuts and poles can create visible discontinuities. pow requires two arguments; all other complex functions require one. Real-only functions such as min, max, floor, ceil, round, mod and atan2 are not supported for complex inputs.

2D plotting — choosing a plot type

  • Function: one real expression in x, e.g. max(0,sin(x)).
  • Parametric: two real expressions in one chosen parameter t, u or v, e.g. 2cos(t) and 2sin(t). Imported legacy curves may use u=v compatibility.
  • Implicit: a real equation in x,y, e.g. x^2+y^2=4; without =, the expression is set to zero.
  • Vector field: real components X(x,y) and Y(x,y), e.g. -y and x.
  • Domain coloring: one complex expression in z, e.g. z^2+1. The colored background sits behind the grid and axes.
  • 3D plotting: use the dedicated 3D workspace for real surfaces, implicit surfaces, vector fields and supported complex domain-coloring views. Choose mesh/detail and color controls in 3D Settings.

Settings and export

Use Settings for background, guides, snapping, plot detail and evaluation limits, label and interaction preferences, theme, and 3D options. High resolution or many simultaneous plots may slow rendering; an undefined expression (such as 1/0) can leave gaps. Not every expression has a finite real value.

Save produces editable JSON. Export produces SVG or raster images (PNG, WebP, JPEG), with controls for crop, scale, guides and transparency. JPEG cannot retain transparency. Restricted TikZ/tikz-cd exports support only applicable objects and may omit unsupported visual details; check the exported result.

What is not supported

The formula parser does not execute arbitrary scripts, custom function definitions, conditionals, arrays, summation or integration syntax, symbolic differentiation, or LaTeX commands. A comma is valid only within a supported multi-argument function call. Inputs are evaluated numerically and sampled at finite resolution. If a curve or surface looks incomplete, inspect its domain, singularities and sampling settings.

MathIllustrator 使用指南

在浏览器中创建几何构造、数学图示和二维／三维图形。JSON 用于保存可编辑项目；图片导出不能代替项目备份。

开始使用

  1. 从几何、交换图工具中选择构造，或在表达式框旁选择绘图模式。
  2. 按工具提示点击画布，或输入表达式并按 Enter。
  3. 使用移动工具选择对象，在属性面板中编辑；在对象列表中搜索、隐藏、锁定、排序、删除。
  4. 定期保存 JSON；使用导出获得 SVG、PNG、WebP、JPEG。

界面操作

左侧对象列表支持拖动排序（键盘 Alt+↑/↓），属性面板编辑当前对象；右侧工具分组可折叠。移动用于选择，平移用于移动视野。Escape 可取消正在进行的操作；撤销／重做可恢复修改。桌面端拖动分隔线改变面板尺寸；窄屏点击外部或按 Escape 关闭侧栏。语言、主题和画布背景可独立设置。数学标签默认 LaTeX，逐字文字可在属性中选择纯文本。

几何与交换图

几何工具包含点线、圆和圆锥曲线、多边形、交点、变换、轨迹等。按提示依次选择构造点或对象；派生对象通常随原对象移动。交换图先放置节点，再用态射连接；属性中可调箭头、标签位置与线型，密集图示仍可能需要手动调整。

数学表达式语法

表达式使用数值计算语法，不是 JavaScript 或 LaTeX。支持 + - * / ^、括号和省略乘号，例如 2pi、3x、2sin(x)、(x+1)(x-1)。函数必须带括号，多个参数以逗号隔开。常数 pi、e 适用于实数和复数；i 仅用于复数。名称大小写不敏感。角度以弧度计算。

复数输入使用 z 和虚数单位 i；例如 sin(z)、conj(z)、abs(z)、pow(z,2)。re/im/abs/arg/norm 的结果为实数（以虚部为零的复数表示）；norm(z)=|z|^2；arg 为 −π 至 π 之间的弧度。对数、开方、复数幂与反函数采用主值分支；分支切口与极点可能导致图像不连续。pow 为双参数，其余为单参数。复数不支持 min/max/floor/ceil/round/mod/atan2 等仅限实数的函数。

二维绘图：选择绘图模式

  • 函数：以 x 为自变量，例如 max(0,sin(x))。
  • 参数曲线：两条实数表达式使用同一个 t/u/v 参数，例如 2cos(t) 与 2sin(t)；旧项目保留 u=v 兼容性。
  • 隐式：以 x,y 为变量，输入 x^2+y^2=4；未写等号时以零为等值线。
  • 向量场：两个实数分量，例如 -y、x。
  • 定义域着色：以 z 为变量，例如 z^2+1，颜色绘制在网格与坐标轴下方。
  • 三维：使用独立三维工作区构造曲面、隐式图、向量场及支持的复数着色视图。

设置、保存与限制

设置可控制网格、吸附、背景、绘图精度、计算预算、标签和三维外观。大量对象或高分辨率会降低速度；极点和无定义值可能造成曲线断裂。保存导出的是可编辑 JSON，图片导出可选择裁切、比例和辅助线。JPEG 不支持透明背景；TikZ/tikz-cd 仅支持部分对象。

表达式不能包含脚本、用户自定义函数、条件语句、数组、符号求导／积分、求和语法或 LaTeX 命令。有限采样并不能保证捕捉所有细节或奇点。
