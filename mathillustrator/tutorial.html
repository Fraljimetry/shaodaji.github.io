MathIllustrator

A local-first mathematical drawing editor. Your project remains editable in JSON; exporting an image does not replace that project.

Workspace

Objects and Properties are on the left, drawing in the center, and tools on the right. Collapse panels with their arrows. On desktop, drag the slim divider between each sidebar and the canvas to resize it; focus the divider and use ←/→ (Shift for larger steps), Home/End, or double-click to reset. Widths are remembered in this browser, and mobile uses fixed drawers. Use the language selector in the top bar. ⚙ Settings opens the right-hand Settings section; its Interface subsection contains font and point-tool behavior. Tap a section arrow to collapse it, drag its grip to reorder within drawing tools or Settings, or focus the grip and press Alt+↑/↓. To adjust Properties height on desktop, drag the divider above it (or focus it and press ↑/↓; double-click resets). Select Float to move Properties over the canvas: drag its header or lower-right corner to move/resize; use Alt+arrows on the header or arrows on the resize corner for keyboard adjustment. Select Dock to return it to the left. The inspector can also be collapsed. The floating position and sizes are remembered in this browser; mobile always uses the left drawer.

Draw

Basic contains Move and Pan; Point and other constructions are under Geometry, grouped into Points & lines, Circles & conics, Polygons and Curves. Each subgroup can be independently collapsed and reordered by dragging its handle or pressing Alt+↑/↓. Diagrams is followed by Others (Free curve and Text). Choose Geometry tools and click the canvas. Move drags points; Pan shifts the view. Wheel zooms. Polygon and Polyline end with Enter. Free curves can be open or closed, with adjustable smoothing. Recently Deleted lets you recover removed objects. Choose New object style → Object naming to change names for future drawings; existing names stay unchanged. Pick common stroke/fill colors from the swatches in New object style or a selected object’s Properties; use the color picker for custom colors. These appearance settings use paired compact columns; line width and opacity remain separate editable values.

Construction input

A = (0, 0)
B = (3, 2)
Segment(A, B)
Circle(A, B)
f(x) = sin(x) + x^2 / 4

Use explicit multiplication (2*x). Function plotting is approximate near discontinuities and narrow peaks. General 3D and parameter sliders are not yet available.

Diagrams & LaTeX

Choose a Diagram node, then a Morphism from source to target. Newly added diagram labels default to LaTeX math; use \frac{A_1}{B_2}, \alpha\to\beta, or \sqrt{x^2+y^2}. Set Label format in Properties to switch between mathematical typesetting and plain text. Point labels can also opt into LaTeX via Properties. Ordinary text supports a font choice.

Diagram nodes have no border by default. Edit arrow style, curvature and label position in Properties. Imported tikz-cd labels use LaTeX. Complex macros outside the locally bundled math renderer are rejected rather than shown as correct mathematical output.

Save & export

Save downloads editable JSON. SVG uses embedded mathematical vector glyphs; PNG, WebP and JPEG are rasterized locally. Transparency is unavailable in JPEG. Restricted TikZ and tikz-cd exports are disabled for scenes they cannot faithfully represent. Browser storage is a convenience, not a substitute for project downloads.

Limits & documentation

This is not a symbolic algebra system, a general 3D modeller or a PDE solver. Mathematical spacing and collision avoidance may need manual adjustment. For original workflows, corner cases and technical verification, see technical documentation and extended historical guide (older feature descriptions may be obsolete).

MathIllustrator 快速指南

本地优先的数学绘图工具。项目可保存为可继续编辑的 JSON，不会将图像导出误认为项目备份。

界面

左侧为对象及属性，中间为画布，右侧为工具。侧栏可折叠。顶部可切换语言。点击 ⚙ 设置 可定位到右侧「设置」，其中「界面」包含字体与点工具选项。点击分区箭头收起内容；拖动把手或聚焦后按 Alt+↑/↓ 可调整同类分区的顺序。属性面板可收起。在桌面端，拖动属性上方的横向分隔线可调整高度，也可聚焦后按 ↑/↓，双击恢复默认。点击浮动可将属性面板移到画布上方；拖动标题移动，拖动右下角调整大小，键盘 Alt+方向键可移动窗口，聚焦右下角后使用方向键可改变大小。点击停靠返回左侧。布局保存在当前浏览器中；手机上仍使用左侧抽屉。

绘图

「基本」包括移动和平移；点和其他几何工具位于「几何」，并分成「点与直线」「圆与圆锥曲线」「多边形」「曲线」四组。各组可单独折叠，拖动组旁把手或按 Alt+↑/↓ 调整各组顺序。交换图之后的「其他」包含自由曲线和文字。选择几何工具后点击画布。移动工具可拖动点；平移工具移动视图；滚轮缩放。多边形及折线按 Enter 完成。自由曲线可设为开放或闭合，并调整平滑程度。意外删除可以在「最近删除」中恢复。在「新对象样式 → 对象命名」可设置新建对象的命名方式，已有名称不会改变。可在「新对象样式」或选中对象的「属性」中直接点击常用线条／填充色；自定义颜色仍可通过颜色选择器设置。外观控制以紧凑双列显示，线宽和不透明度仍可单独编辑。

命令输入

A = (0, 0)
B = (3, 2)
Segment(A, B)
Circle(A, B)
f(x) = sin(x) + x^2 / 4

乘法目前需要写明，例如 2*x。函数图像采用数值采样，可能漏掉奇点附近的细节；通用 3D 与参数滑块尚未实现。

交换图与 LaTeX

先创建「图节点」，再通过「态射」连接。新图节点及箭头标签默认用 LaTeX 排版，例如 \frac{A_1}{B_2}、\alpha\to\beta。在「属性 → 标签格式」中可切换数学公式与普通文字。点标签也可自行启用 LaTeX，普通文字可选择字体。

图节点默认没有边框。箭头样式、弯曲程度及标签位置均可在属性中修改。导入 tikz-cd 后使用数学公式排版；不支持的宏会明确报错。

保存与导出

「保存」下载可编辑的 JSON。SVG 可包含数学公式的矢量字形，PNG/WebP/JPEG 为本地位图转换；JPEG 不支持透明背景。某些图形无法无损导出为 TikZ 或 tikz-cd，对应选项会停用。请定期下载 JSON 备份。

局限与参考

目前不是符号计算器、通用三维建模器或偏微分方程求解器。复杂图形可能仍需人工调整标签位置。可查看 技术文档 和 旧版详细手册（部分历史功能描述已过时）。
