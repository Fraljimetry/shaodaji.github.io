MathIllustrator

A local-first mathematical drawing editor. Your project remains editable in JSON; exporting an image does not replace that project.

Workspace

Objects and Properties are on the left, drawing in the center, and tools on the right. Collapse panels with their arrows. On desktop, drag the slim divider between each sidebar and the canvas to resize it; focus the divider and use ←/→ (Shift for larger steps), Home/End, or double-click to reset. Widths are remembered in this browser, and mobile uses fixed drawers. Click the language control once to switch English and Chinese; this guide automatically follows the editor language. The right-hand Settings section includes Interface options for font and point-tool behavior. Tap a section arrow to collapse it, drag its grip to reorder within drawing tools or Settings, or focus the grip and press Alt+↑/↓. To adjust Properties height on desktop, drag the divider above it (or focus it and press ↑/↓; double-click resets). Properties starts floating on desktop. Select Float to move Properties over the canvas: drag its header or lower-right corner to move/resize; use Alt+arrows on the header or arrows on the resize corner for keyboard adjustment. Select Dock to return it to the left. Objects and Tools have independent Float/Dock buttons: drag each floating header to move, drag the lower-right corner to resize, or use Alt+arrows on the focused header and arrows on the focused corner. Each panel remembers its own geometry; on mobile, all panels return to their drawers. The current theme is inherited from the home site unless explicitly set in the editor, and the tutorial follows the editor theme. Only a docked Properties inspector can be collapsed; floating Properties remains expanded and its collapse button is disabled. The floating position and sizes are remembered in this browser; mobile always uses the left drawer.

Draw

Basic contains Move and Pan; Point and other constructions are under Geometry, grouped into Points & lines, Circles & conics, Polygons and Curves. Each subgroup can be independently collapsed and reordered by dragging its handle or pressing Alt+↑/↓. Diagrams is followed by Others (Free curve and Text). Choose Geometry tools and click the canvas. For an ellipse, click its two foci, then a third point on the ellipse (a degenerate choice is rejected). Existing two-corner ellipses in older projects still display. Move drags points; Pan shifts the view. When the Interface auto-mode checkbox is enabled (default), one completed construction returns to Pan, and dragging a movable object from Pan switches to Move. Disable it to retain the chosen tool. Wheel zooms. Polygon and Polyline end with Enter. Free curve joining magnetically attracts endpoints to nearby visible objects; the Open choice disables attachment and closure. Smoothing is adjustable. Geometry options organizes snapping controls under Snap and visibility controls under Show. Snap points to objects (on by default) attracts newly placed and moved points within 16 screen pixels of visible geometry; this saves the snapped coordinate, not a live dependency. Snap to grid and existing-point snapping remain separately adjustable. Recently Deleted lists original names and lets you restore removed objects. Choose New object style → Object naming to change names for future drawings; existing names stay unchanged. Pick common stroke/fill colors from the swatches in New object style or a selected object’s Properties; use the color picker for custom colors. These appearance settings use paired compact columns; line width and opacity remain separate editable values.

Controls and settings

All editor controls are intentionally short; this guide contains their detailed meanings. The book icon in the toolbar opens this tutorial. The status near the canvas names the active tool; no separate help bubble is required. Settings → Plotting → Plot detail: Fast prioritizes responsiveness, Balanced is the default, and Detailed samples more densely but can be slower; sampling can still miss narrow spikes, poles or rapid oscillations. Geometry options → Free curves: Open keeps a path open with no endpoint attraction; Join & snap joins nearby endpoints with a corner or smooth tangent and attracts both ends near other visible geometry. Off, Gentle, Medium, Strong and Ultra control curve smoothing/simplification. Regular polygon sides sets the default number of vertices. Snap → Grid uses Snap interval, Points attracts to existing point anchors, and Objects attracts newly placed or moved points to visible geometry. Show → Grid, Axes, and Point labels control canvas overlays; label placement can be Standard or Avoid overlap. New object style includes stroke and fill color pickers and ten swatches (two rows of five), Width, Opacity, Point size and naming styles (PascalCase, camelCase and snake_case). Page & appearance includes Infinite/A4/Letter canvases, Viewport/Page export area, Export guides, transparent background, raster scale, background color, and light/dark themes. Transparent exports support SVG, PNG and WebP, not JPEG. Interface → Auto Pan / Move enables both return to Pan after one construction and switch to Move on object drag. Rearrange sections with their grips, or focus a grip and use Alt+Up/Down.

In Properties, Name is the editable object identifier; names must be unique and nonempty. Referenced constructions follow their linked anchors. Freehand paths currently do not expose individual control vertices, and function samples have finite resolution. Text and arrow labels accept line breaks with Enter; click elsewhere to apply. For diagram arrows, choose Direct, Avoid nodes, Fewer crossings, or All arrows (the latter is limited to 48 arrows). These are best-effort screen-space routes, not a global guarantee; crossings and suppressed routes may remain, and bend is ignored when auto-routing. Arrow labels can be dragged by their visible handle in Move mode. Collision avoidance may fail for crowded labels, and manual positioning disables automatic placement. Auto label placement is not exported to TikZ. The Label position field accepts 0.05–0.95, Label distance and shift use CSS pixels. The contextual object icons mean Hide, Lock and Delete; hover or keyboard focus reveals their accessible labels. When locked, unlock via the object menu to edit. The tikz-cd importer accepts a supported environment and replaces the project only after confirmation. Export disables unavailable formats rather than silently changing their meaning.

Construction input

A = (0, 0)
B = (3, 2)
Segment(A, B)
Circle(A, B)
C = (1, 3)
Ellipse(A, B, C)
f(x) = sin(x) + x^2 / 4

Use explicit multiplication (2*x). Function plotting is approximate near discontinuities and narrow peaks. General 3D and parameter sliders are not yet available.

Diagrams & LaTeX

Choose a Diagram node, then a Morphism from source to target. Newly added diagram labels default to LaTeX math; use \frac{A_1}{B_2}, \alpha\to\beta, or \sqrt{x^2+y^2}. Set Label format in Properties to switch between mathematical typesetting and plain text. Point labels can also opt into LaTeX via Properties. Ordinary text supports a font choice.

Diagram nodes have no border by default. Edit arrow style, curvature and label position in Properties. Imported tikz-cd labels use LaTeX. Complex macros outside the locally bundled math renderer are rejected rather than shown as correct mathematical output.

Save & export

Save downloads editable JSON. SVG uses embedded mathematical vector glyphs; PNG, WebP and JPEG are rasterized locally. Transparency is unavailable in JPEG. Restricted TikZ and tikz-cd exports are disabled for scenes they cannot faithfully represent. Browser storage is a convenience, not a substitute for project downloads.

Limits & documentation

This is not a symbolic algebra system, a general 3D modeller or a PDE solver. Mathematical spacing and collision avoidance may need manual adjustment. For original workflows, corner cases and technical verification, see technical documentation and extended historical guide (older feature descriptions may be obsolete).

MathIllustrator 快速指南

本地优先的数学绘图工具。项目可保存为可继续编辑的 JSON，不会将图像导出误认为项目备份。

界面

左侧为对象及属性，中间为画布，右侧为工具。侧栏可折叠。顶部单击语言控件即可中英文切换，教程语言随编辑器自动更新。右侧「设置」中的「界面」包含字体与点工具选项。点击分区箭头收起内容；拖动把手或聚焦后按 Alt+↑/↓ 可调整同类分区的顺序。属性面板桌面端默认浮动，浮动时始终展开且折叠按钮停用；停靠后可收起。在桌面端，拖动属性上方的横向分隔线可调整高度，也可聚焦后按 ↑/↓，双击恢复默认。点击浮动可将属性面板移到画布上方；拖动标题移动，拖动右下角调整大小，键盘 Alt+方向键可移动窗口，聚焦右下角后使用方向键可改变大小。点击停靠返回左侧。对象和工具面板也可独立浮动／停靠：拖动浮动标题移动，拖动右下角调整大小，聚焦标题后可按 Alt+方向键移动，聚焦右下角后用方向键缩放。浮动位置分别保存，手机端自动还原为抽屉。未手动设置主题时默认跟随站点首页，教程与编辑器保持同一主题。布局保存在当前浏览器中；手机上仍使用左侧抽屉。

绘图

「基本」包括移动和平移；点和其他几何工具位于「几何」，并分成「点与直线」「圆与圆锥曲线」「多边形」「曲线」四组。各组可单独折叠，拖动组旁把手或按 Alt+↑/↓ 调整各组顺序。交换图之后的「其他」包含自由曲线和文字。选择几何工具后点击画布。画椭圆时先点两个焦点，再点椭圆上的第三点；无效的退化位置会被拒绝，旧项目的两角点椭圆仍可显示。移动工具可拖动点；平移工具移动视图。默认勾选的自动模式会在完成一次构造后返回平移模式，在平移模式中拖动对象则切换为移动模式；取消勾选可保持当前工具。滚轮缩放。多边形及折线按 Enter 完成。自由曲线启用连接时，首尾靠近可见对象会自动吸附，选择保持开放则禁用吸附和闭合；平滑程度可调整。「几何选项」将复选框按「吸附」和「显示」分组；默认开启「点吸附到附近对象」，新建或移动点靠近可见曲线时以 16 屏幕像素为阈值吸附到曲线，保存坐标但不建立持续依赖；网格和已有点吸附仍可分别设置。「最近删除」显示对象原名，并支持恢复。在「新对象样式 → 对象命名」可设置新建对象的命名方式，已有名称不会改变。可在「新对象样式」或选中对象的「属性」中直接点击常用线条／填充色；自定义颜色仍可通过颜色选择器设置。外观控制以紧凑双列显示，线宽和不透明度仍可单独编辑。

控制与设置说明

编辑器中使用简短的标签，详细含义集中在本教程。顶部书本图标打开教程；画布上方显示当前工具名称。「绘图 → 绘图精度」的快速强调速度，均衡是默认值，精细采用更多采样点但仍可能漏掉极窄尖峰、极点或快速振荡。「几何选项 → 自由曲线」的开放不连接首尾也不吸附；连接并吸附会在端点足够接近时连接（切线近似平滑，否则保留尖角），还会吸附到附近可见几何对象。「曲线平滑」可选关闭、轻度、中度、强、超平滑。「正多边形边数」调整新建多边形的默认边数。「吸附」中的网格使用设定间隔，点吸附已有锚点，对象吸附可见几何图形；「显示」中的网格、坐标轴、点标签决定画布显示内容，标签布局可选标准或避免重叠。「新对象样式」包含线条与填充颜色选择器、各十个常用色块（每排五个）、线宽、不透明度、点大小，以及大驼峰／小驼峰／下划线式命名。「画布与外观」包括无限/A4/Letter 画布、当前视图或页面导出范围、参考线、透明背景、位图比例、背景色及浅色/深色主题。SVG/PNG/WebP 可透明，JPEG 不可。「界面 → 自动平移／移动」控制构造完成后自动返回平移，以及在平移模式拖动对象时切换移动。拖动分区把手调整顺序，聚焦后可按 Alt+↑/↓。

「属性 → 名称」是对象的唯一可编辑名称，不能为空或重复；有引用关系的构造随其锚点变化。自由曲线暂不支持逐点编辑，函数采样存在有限分辨率。文本及箭头标签可按 Enter 插入换行，点击外部提交。态射路径可选直接连线、避让节点、减少交叉、所有箭头（最多处理 48 支）；这些都是尽力处理屏幕空间中的交叉，不能保证完全无交叉，自动布线时不使用手动弯曲数值。在移动模式可以拖动箭头标签手柄；拥挤时标签避让可能失败，手动移动后会转为手动布局，自动位置也不能完整导出到 TikZ。标签位置范围 0.05–0.95，距离与偏移以像素计。对象菜单的眼睛、锁及垃圾桶分别代表隐藏、锁定、删除，鼠标悬停或键盘聚焦可查看名称。对象锁定后需先解锁才能编辑。导入 tikz-cd 时粘贴受支持的环境，确认后才替换当前项目；不可导出的格式会停用。

命令输入

A = (0, 0)
B = (3, 2)
Segment(A, B)
Circle(A, B)
C = (1, 3)
Ellipse(A, B, C)
f(x) = sin(x) + x^2 / 4

乘法目前需要写明，例如 2*x。函数图像采用数值采样，可能漏掉奇点附近的细节；通用 3D 与参数滑块尚未实现。

交换图与 LaTeX

先创建「图节点」，再通过「态射」连接。新图节点及箭头标签默认用 LaTeX 排版，例如 \frac{A_1}{B_2}、\alpha\to\beta。在「属性 → 标签格式」中可切换数学公式与普通文字。点标签也可自行启用 LaTeX，普通文字可选择字体。

图节点默认没有边框。箭头样式、弯曲程度及标签位置均可在属性中修改。导入 tikz-cd 后使用数学公式排版；不支持的宏会明确报错。

保存与导出

「保存」下载可编辑的 JSON。SVG 可包含数学公式的矢量字形，PNG/WebP/JPEG 为本地位图转换；JPEG 不支持透明背景。某些图形无法无损导出为 TikZ 或 tikz-cd，对应选项会停用。请定期下载 JSON 备份。

局限与参考

目前不是符号计算器、通用三维建模器或偏微分方程求解器。复杂图形可能仍需人工调整标签位置。可查看 技术文档 和 旧版详细手册（部分历史功能描述已过时）。
