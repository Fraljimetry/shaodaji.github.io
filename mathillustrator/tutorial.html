MathIllustrator

A local-first mathematical drawing editor. Your project remains editable in JSON; exporting an image does not replace that project.

Workspace

  • Objects and Properties stay docked on the left, with the canvas in the center and Tools on the right. None of these panels floats above the drawing.
  • On desktop, drag the vertical dividers next to the canvas to resize Objects and Tools; focus a divider and use ←/→ (Shift for larger steps), Home/End, or double-click to reset.
  • Drag the horizontal divider above Properties to change its height, or focus it and use ↑/↓, Home/End, or double-click to reset. Properties can be expanded or collapsed using its ± button, independent of the Objects list.
  • Previously saved Float/Dock preferences are ignored; only dock widths/heights and collapsed states are retained in browser preferences, not project JSON. Mobile uses fixed left/right drawers, never floating overlays.
  • Use the language control to switch English/Chinese; this tutorial follows the editor language and theme. In Settings you can change the UI font and Auto Pan / Move behavior.
  • Tool groups and settings sections can be collapsed or reordered by dragging their handles or focusing a handle and pressing Alt+↑/↓.

Draw

  • Basic contains Move and Pan;Point and other constructions are under Geometry, grouped into Points & lines, Circles & conics, Polygons and Curves.
  • Each subgroup can be independently collapsed and reordered by dragging its handle or pressing Alt+↑/↓.
  • Free curve belongs to Geometry → Curves; Text belongs to Diagrams. For an ellipse, click two foci and then a third point on its boundary; diagonal foci now render with the correct screen-space orientation.
  • If that last click is close to an existing anchor on the focal segment, the editor keeps your actual clicked position rather than snapping it to an invalid ellipse; clicking exactly on the focal segment is still rejected.
  • The two focus clicks can be close without collapsing to the same anchor. Existing two-corner ellipses in older projects still display. Move drags points; Pan shifts the view.
  • In Move, Ctrl-click (or Cmd-click) and Shift-click on objects or list rows toggle extra selections; Ctrl-click also cycles overlapping canvas objects.
  • Drag a selection rectangle from empty canvas: left-to-right includes fully enclosed visible objects, right-to-left includes touching ones. Hold Shift to add objects with a rectangle.
  • Escape or double-clicking the canvas in Move/Pan clears the selection; Escape also cancels an unfinished rectangle; a normal click replaces the selection. When several objects are selected, Properties edits their shared editable Stroke, Fill, Line width, Opacity and Point size together in one undo step.
  • Fill applies only to fill-capable types, point radius only to points, and locked objects are skipped; mixed numbers are blank until changed.
  • Multi-selection is temporary and not saved to project JSON. Dragging a point does not move the entire multi-selection.
  • When the Interface auto-mode checkbox is enabled (default), one completed construction returns to Pan, and dragging a movable object from Pan switches to Move.
  • Disable it to retain the chosen tool. Wheel zooms. Polygon and Polyline end with Enter.
  • Free curve joining attracts endpoints only to visible geometry; the Open choice disables attachment and closure. Freehand and spline snapping follows their rendered smooth curves, not their hidden control polygons or unfiltered pen samples.
  • New projects default to Ultra-smooth: arc-length resampling and Gaussian low-pass filtering reduce jitter; fewer samples keep the path responsive.
  • Near-closed free curves now use aggressive, periodic smoothing across a wide region on both sides of the join, instead of adding a short patch that leaves a hook. The original stroke samples and saved smoothing choice remain unchanged; Open still disables automatic closing.
  • Geometry options organizes snapping controls under Snap and visibility controls under Show.
  • Objects snapping (on by default) attracts newly placed and moved points, and new construction vertices, within 10 screen pixels of supported visible geometry; this saves the snapped coordinate, not a live dependency.
  • Grid remains visible in new projects, but Grid snapping starts OFF, so points can be placed freely. Existing-anchor and object snapping remain independently adjustable.
  • Recently Deleted lists original names and lets you restore removed objects. Choose New object style → Object naming to change names for future drawings; existing names stay unchanged.
  • Pick common stroke/fill colors from the swatches in New object style or a selected object’s Properties; use the color picker for custom colors.
  • The selected-object Properties and New object style use matching two-column color palettes: all ten swatches remain square with evenly spaced gaps (five per row), and muted Cyan replaces the former bright Sky. Compact numeric fields (including bulk Point size) keep values on the left, inputs inline to the right of captions, and native spinner buttons on the right; the Background picker aligns with other Settings dropdowns.

Controls and settings

  • All editor controls are intentionally short; this guide contains their detailed meanings. The book icon in the toolbar opens this tutorial. The status near the canvas names the active tool; no separate help bubble is required.
  • Settings → Plotting → Plot detail: Fast prioritizes responsiveness, Balanced is the default, and Detailed samples more densely but can be slower; sampling can still miss narrow spikes, poles or rapid oscillations.
  • Geometry options → Free curves: Open keeps a path open with no endpoint attraction;Join & snap attracts endpoints to nearby visible geometry, then blends the whole closing seam aggressively, including old curves with stored corner metadata. No extra corner is intentionally introduced.
  • Off, Gentle, Medium, Strong and Ultra control curve smoothing/simplification; Ultra is the default for newly created projects, using lower-density resampling plus a Gaussian low-pass filter. Regular polygon sides sets the default number of vertices.
  • Snap → Grid uses Snap interval, Points attracts to existing point anchors, and Objects also attracts construction vertices and moved points to visible geometry. Object snapping ignores hidden shapes and uses the visible angle arc rather than its invisible defining arms. Plotted-function and morphism-stroke snapping still need dedicated handling.
  • Show → Grid, Axes and Labels control overlays. Label placement defaults to Avoid overlap in new projects: point labels and optional geometric-object labels share the same screen-space collision layout. Standard retains the original positions; dense labels can still require manual revision.
  • New object style includes stroke and fill color pickers and ten swatches (two rows of five), Width, Opacity, Point size and naming styles (PascalCase, camelCase and snake_case). Page & appearance includes Infinite, A3/A4/A5, Letter, Legal, Tabloid, Square and 16:9 frames.
  • Image bounds sets which rectangle is exported: View exports everything visible in the drawing viewport, while Page crops to the selected finite page frame (on Infinite it behaves like View).
  • Grid/axes in export includes whichever grid and axes are enabled under Show; new projects include these guides by default; uncheck to omit them from images.
  • These controls affect SVG/PNG/JPEG/WebP images, not project JSON or TikZ coordinates.
  • Raster resolution (1×–4×) multiplies pixel dimensions for PNG/JPEG/WebP; SVG remains vector. Theme (light/dark) changes the editor interface, while Background sets the drawing/image background.
  • Transparent background is OFF by default. When enabled, it overrides background color for SVG/PNG/WebP. Transparent exports support SVG, PNG and WebP, not JPEG. Interface → Auto Pan / Move enables both return to Pan after one construction and switch to Move on object drag.
  • Rearrange sections with their grips, or focus a grip and use Alt+Up/Down.
  • In Properties, Name is the unique referenced object name. Points, Text, nodes and morphisms use their existing label controls; all other geometric objects can now have an optional Displayed label in Plain or LaTeX format. Labels follow live anchor movement and export in JSON/SVG; unsupported restricted TikZ export is disabled. Referenced constructions follow their linked anchors.
  • Freehand paths currently do not expose individual control vertices, and function samples have finite resolution.
  • Text and arrow labels accept line breaks with Enter; click elsewhere to apply. For diagram arrows, choose Direct, Avoid nodes, Fewer crossings, or All arrows (the latter is limited to 48 arrows).
  • These are best-effort screen-space routes, not a global guarantee; crossings and suppressed routes may remain, and bend is ignored when auto-routing. New arrow labels automatically seek clear space away from node boxes, other arrow strokes and Text objects; dense scenes can still require manual placement. In Move mode drag the displayed arrow label itself; labels and their invisible hit areas are painted above later diagram objects so overlapping shapes do not block editing. Undo/redo restores label shifts; Escape cancels an active drag.
  • Collision avoidance may fail for crowded labels, and manual positioning disables automatic placement.Auto label placement is not exported to TikZ.
  • The Label position field accepts 0.05–0.95, Label distance and shift use CSS pixels.
  • The contextual object icons mean Hide, Lock and Delete; hover or keyboard focus reveals their accessible labels. When locked, unlock via the object menu to edit.
  • The tikz-cd importer accepts a supported environment and replaces the project only after confirmation. Export disables unavailable formats rather than silently changing their meaning.

Geometry tools

Choose Essential only for a compact geometry palette (enabled by default), or uncheck it to show every available tool. This changes only the editor palette; no object is deleted and project JSON remains identical.

  • Points & lines: Midpoint follows two anchors. Ray extends forward only. Perp. bisector remains orthogonal to its defining segment.
  • Parallel through point / Perpendicular through point: Turn off Essential only. Choose the tool, click an existing point (or free position), then click an existing straight object. The new infinite line keeps its point and follows the source direction when either changes.
  • Intersection point: Click two crossing straight objects. Lines, segments, rays, bisectors and through-point lines are supported; the intersection must lie in both domains.
  • Circle–circle intersections: Turn off Essential only, then click two different circles in Circles & conics. Two crossing circles create two live point objects; tangency creates one. Disjoint, contained or coincident circles create none. Changing their centers or radii updates the dependent points; changes that would invalidate an existing point are rejected.
  • Line–circle intersections: Disable Essential only, then click one straight object and one circle, in either order. A secant constructs two dependent points, a tangent one, and a nonintersecting pair none. A segment or ray produces only roots in its actual domain. Each constructed point retains its signed branch when defining objects move. Includes 2-point and 3-point circles; ellipses and arbitrary curves are not yet supported.
  • Dependents: New lines and intersections preserve their source references. Move defining points to update the construction. An anchor move is refused if it would erase a previously valid intersection branch; deleting a source also deletes its dependents. Press Escape or switch tools to cancel a partial construction.
  • Circles & conics: Diameter circle uses two opposite ends of the diameter and constructs a linked midpoint; 3-point circle uses three noncollinear points and automatically updates when the anchors move. Ellipse continues to use two foci and a third point.
  • Polygons: Triangle finishes after three vertices; Quadrilateral finishes after four. Both are saved as ordinary editable polygons. Polygon remains a variable-vertex construction completed with Enter. Each new free-vertex polygon now creates separate editable Segment objects for all sides, sharing its vertex references; deleting the parent also removes owned sides. New rectangles create four individually editable Segments, and new regular polygons create one Segment per side. Each side follows its defining geometry as its two anchors move; individual sides may be styled or deleted, while deleting the parent also deletes its remaining sides. Older saved shapes are never retroactively given new sides.
  • Curves: Free curve, Polyline, Bézier, Spline and Closed spline are together; Bézier uses four control points. A spline passes smoothly through at least three vertices; press Enter to finish.
  • Closed spline closes with a continuous tangent; press Enter to finish. Diagrams now includes Text alongside Diagram node and Morphism.
  • To cancel an unfinished construction, press Escape or choose another tool. Existing constructions, including advanced ones, stay visible if you turn Essential only back on.
  • Ray, perpendicular bisector, 3-point circle and splines retain live geometric dependencies in JSON/SVG; restricted TikZ is disabled for these types rather than silently flattening them.

Construction input

A = (0, 0)
B = (3, 2)
Segment(A, B)
Circle(A, B)
C = (1, 3)
Ellipse(A, B, C)
f(x) = sin(x) + x^2 / 4

Use explicit multiplication (2*x). Function plotting is approximate near discontinuities and narrow peaks. General 3D and parameter sliders are not yet available.

Diagrams & LaTeX

  • Choose a Diagram node, then a Morphism from source to target.Newly added diagram labels default to LaTeX math; use \frac{A_1}{B_2}, \alpha\to\beta, or \sqrt{x^2+y^2}.
  • Set Label format in Properties to switch between mathematical typesetting and plain text.
  • User-entered point and geometric displayed labels default to LaTeX in Properties; automatic object names remain ordinary literal text. Older saved labels keep their recorded format. The Text tool also creates LaTeX by default: enter \alpha+\beta directly or use an optional $...$ wrapper. Choose Plain text from Properties only when literal text is intended.
  • In Properties, Label format switches Text, diagram nodes and morphisms between Plain text and LaTeX math; diagram nodes and morphisms default to LaTeX at creation, even with empty arrow labels. Existing saved text modes are never overwritten.
  • Plain text adds Verdana, Trebuchet, Palatino and Times font choices. The UI font selector also supports them; LaTeX uses the bundled math font.

Diagram nodes have no border by default. Edit arrow style, curvature and label position in Properties. Imported tikz-cd labels use LaTeX. Complex macros outside the locally bundled math renderer are rejected rather than shown as correct mathematical output.

Diagram arrow controls

  • Default math labels: Point labels, object displayed labels, Text, diagram nodes and morphism labels are LaTeX by default for newly created objects. The Properties control is consistently named Label format. Older JSON labels with no format retain their plain-text behavior.
  • Controls: The Properties minus button collapses the docked inspector and plus reopens it. Numeric values begin at the left edge of each input; the two native stepper arrows remain on the right. The Export button uses a subdued blue in dark theme.
  • Grid snap by tool: Choosing Diagram node or Morphism automatically enables grid snapping. Switching back to Geometry or other tools automatically disables it; the Snap checkbox can override the current tool until you switch again. Visible grid, snapping to existing points and snapping to objects are independent.
  • Drag the arrow label directly: In Move mode, drag its visible text, including LaTeX such as \varphi. No separate circular grab handle is shown. Undo reverses the move; Escape cancels an incomplete drag. Locked arrows cannot be dragged.
  • Arrow style: Solid, Dashed, Dotted, Hooked, Hook dashed, Two heads, and Tail bar change only the arrow. Hooked variants use a smooth hook joined to the tail, not a detached ornament. Unsupported semantic export options are disabled instead of silently approximated.
  • Arrow routing: Direct, Avoid nodes, Fewer crossings, and All arrows are available in both languages. Automatic routing is best-effort; crowded diagrams can still require manual adjustment. “Avoid collisions” moves labels; “Swap label side” reverses which side of the arrow carries its label.
  • Signed offsets use a leading minus sign (for example -36), with number steppers on the right. The two label checkboxes are together in Properties. Essential only is checked in new editor layouts; uncheck it to see advanced Geometry.

Save & export

  • Save downloads editable JSON.SVG uses embedded mathematical vector glyphs;PNG, WebP and JPEG are rasterized locally.Transparency is unavailable in JPEG.
  • Restricted TikZ and tikz-cd exports are disabled for scenes they cannot faithfully represent.Browser storage is a convenience, not a substitute for project downloads.

Limits & documentation

  • This is not a symbolic algebra system, a general 3D modeller or a PDE solver.Mathematical spacing and collision avoidance may need manual adjustment.
  • For original workflows, corner cases and technical verification, see technical documentation and extended historical guide (older feature descriptions may be obsolete).

Labels and hooked arrows

  • Name is the object’s unique plain-text identifier; it is never automatically typeset as a math expression.
  • Displayed label is optional and independent. User-entered labels default to LaTeX; clearing one reveals the plain name again. Use Label format → Plain text when needed.
  • Hooked / Hook dashed use a parenthesis-shaped tail joined smoothly to the arrow shaft, rather than a floating curl.
  • The selected-object Point size control stays beside its caption even for multiple selected points. The palette now uses softer Cyan in place of Sky.

MathIllustrator 快速指南

本地优先的数学绘图工具。项目可保存为可继续编辑的 JSON，不会将图像导出误认为项目备份。

界面

  • 对象及属性始终停靠在左侧，中间为画布，工具始终停靠在右侧；三个面板都不再支持浮动覆盖画布。桌面端可拖动左右分隔线调整侧栏宽度，聚焦后用 ←/→（Shift 加速）、Home/End 或双击重置。属性始终停靠在对象列表下方，可通过上方横线拖动调整高度，也可聚焦后按 ↑/↓、Home/End 或双击恢复默认；
  • 属性标题右侧的 ± 用于展开或折叠。旧版保存的浮动状态不会再生效。宽度、高度及折叠状态仅存于当前浏览器，不写入项目 JSON。手机上左右两侧为抽屉，不存在浮动面板。顶部语言按钮切换中英文，教程自动跟随编辑器语言及主题。右侧「设置」可调整字体与自动平移／移动；工具组和设置分区可折叠，并可拖动把手或聚焦后按 Alt+↑/↓ 调整顺序。

绘图

  • 「基本」包括移动和平移；点和其他几何工具位于「几何」，并分成「点与直线」「圆与圆锥曲线」「多边形」「曲线」四组。各组可单独折叠，拖动组旁把手或按 Alt+↑/↓ 调整各组顺序。「曲线」包含自由曲线；「交换图」中包含文字。选择几何工具后点击画布。画椭圆时先点两个不同的焦点，再点不位于焦点连线线段上的第三点。
  • 若第三次点击靠近焦点线段上的已有点，程序不会把有效点击错误吸附为退化椭圆；实际点击正好落在焦点线段上仍会被拒绝。相邻但不同的两个焦点不再被强制合并；旧项目的两角点椭圆继续兼容。移动工具可拖动点；
  • 平移工具移动视图。在移动模式中，可使用 Ctrl／Cmd 或 Shift 单击画布对象或对象列表行来增减多选；Ctrl 单击还能轮换重叠对象。从画布空白处拖出选框：从左向右只选择完全包含的可见对象，从右向左选中与选框相交的对象；按 Shift 拖框可增选。按 Esc 或在移动／平移模式双击画布可清空选中项；Esc 还可取消未完成的框选，普通单击替换选中项。
  • 多选后可在属性面板一次性编辑支持的线条色、填充色、线宽、不透明度和点大小，每次修改只有一条撤销记录。填充只作用于可填充对象，点大小只作用于点，锁定对象不参与修改；不同的数字值显示为空直至输入新值。
  • 多选仅保存在当前编辑器，不写入项目 JSON。拖动某个点不会整体移动全部选中对象。默认勾选的自动模式会在完成一次构造后返回平移模式，在平移模式中拖动对象则切换为移动模式；取消勾选可保持当前工具。滚轮缩放。多边形及折线按 Enter 完成。自由曲线启用连接时，首尾靠近可见对象会自动吸附，选择保持开放则禁用吸附和闭合；
  • 新项目默认「超平滑」，以等弧长降采样和高斯数值滤波减小抖动，降低采样点密度以兼顾速度；旧项目保留已存的平滑选项。自动闭合不再仅插入一小段贝塞尔补丁，而是对首尾两侧较宽范围同时强力平滑，消除尖锐勾角；存储的笔迹采样点不被更改。
  • 「几何选项」将复选框按「吸附」和「显示」分组；新项目的网格吸附默认关闭，点可以自由落在非网格位置，网格仍可显示。默认开启「点吸附到附近对象」，新建点、移动点和构造顶点靠近可见几何对象时以 10 屏幕像素为阈值吸附到曲线，保存坐标但不建立持续依赖；网格和已有点吸附仍可分别设置。「最近删除」显示对象原名，并支持恢复。在「新对象样式 → 对象命名」可设置新建对象的命名方式，已有名称不会改变。
  • 可在「新对象样式」或选中对象的「属性」中直接点击常用线条／填充色；自定义颜色仍可通过颜色选择器设置。新对象样式与属性编辑均采用一致的双列颜色区，每种颜色两排、每排五个色块；
  • 线宽、不透明度、点大小输入框位于标签右边，微调箭头位于输入框右侧，数值居左。紫色替换青绿色，十个色块均匀填满每行。

控制与设置说明

  • 十种常用颜色保持正方形，通过调节间距填满一行；背景颜色选择框与其它下拉框等宽。
  • 自由曲线和样条曲线的吸附依据屏幕上实际平滑后的路径，不会吸附到不可见的原始采样折线。
  • 新建项目默认使用“避免重叠”标签布局，点标签和几何形状的显示标签共用避让。
  • 编辑器中使用简短的标签，详细含义集中在本教程。顶部书本图标打开教程；画布上方显示当前工具名称。「绘图 → 绘图精度」的快速强调速度，均衡是默认值，精细采用更多采样点但仍可能漏掉极窄尖峰、极点或快速振荡。「几何选项 → 自由曲线」的「开放」不连接首尾也不吸附；「连接并吸附」会在端点足够接近时闭合，并在闭合点两侧较宽范围采用周期性数值平滑，不再故意留下尖角，还会吸附到附近可见几何对象。
  • 「曲线平滑」可选关闭、轻度、中度、强、超平滑，新建项目默认超平滑并进行较低密度的等弧长采样及高斯滤波。「正多边形边数」调整新建多边形的默认边数。
  • 「吸附」中的网格使用设定间隔，默认关闭；点吸附已有锚点，对象吸附也作用于构造顶点、移动点和可见几何图形，默认 10 屏幕像素。角度只吸附可见圆弧，不再吸附不可见的构造边；函数图像与态射路径仍待专项完善。「显示」中的网格、坐标轴、标签决定画布显示内容，标签布局可选标准或避免重叠。「新对象样式」包含线条与填充颜色选择器、各十个常用色块（每排五个）、线宽、不透明度、点大小，以及大驼峰／小驼峰／下划线式命名。「画布与外观」提供无限、A3/A4/A5、Letter、Legal、Tabloid、正方形、16:9 横向页面。图像范围的「视图」导出当前看到的画布；
  • 「页面」仅导出所选有限页面边框内的区域（无限画布时与「视图」相同）。导出网格／坐标轴新项目默认勾选，会在图像中包含「显示」里已开启的网格和坐标轴；
  • 不勾选时图像不带这些辅助线，项目 JSON 不受影响。位图分辨率 1×–4× 仅改变 PNG/JPEG/WebP 像素数，SVG 为矢量图。主题控制编辑器界面的明暗，背景色决定画布及图像底色，透明背景默认关闭；勾选后可在支持的图像格式中覆盖背景色。SVG/PNG/WebP 可透明，JPEG 不可。
  • 「界面 → 自动平移／移动」控制构造完成后自动返回平移，以及在平移模式拖动对象时切换移动。拖动分区把手调整顺序，聚焦后可按 Alt+↑/↓。
  • 「属性 → 名称」是唯一的对象引用名称，不能为空或重复。点、文字、交换图节点和态射沿用原有标签编辑；其他几何对象也能设置「显示标签」和普通文本／LaTeX 格式，随锚点移动并存入 JSON/SVG。无法忠实表示时，TikZ 会禁用。自由曲线暂不支持逐点编辑，函数采样存在有限分辨率。文本及箭头标签可按 Enter 插入换行，点击外部提交。态射路径可选直接连线、避让节点、减少交叉、所有箭头（最多处理 48 支）；这些都是尽力处理屏幕空间中的交叉，不能保证完全无交叉，自动布线时不使用手动弯曲数值。
  • 在移动模式可以直接拖动箭头标签；拥挤时标签避让可能失败，手动移动后会转为手动布局，自动位置也不能完整导出到 TikZ。标签位置范围 0.05–0.95，距离与偏移以像素计。对象菜单的眼睛、锁及垃圾桶分别代表隐藏、锁定、删除，鼠标悬停或键盘聚焦可查看名称。对象锁定后需先解锁才能编辑。 导入 tikz-cd 时粘贴受支持的环境，确认后才替换当前项目；不可导出的格式会停用。

交换图箭头与吸附

  • LaTeX 默认标签：新建的点标签、几何对象显示标签、文字、交换图节点以及态射标签统一默认 LaTeX。属性中统一称为「标签格式」，需要逐字普通文本时可手动选择。没有格式字段的旧项目继续按旧的普通文本方式显示。
  • 标签拖动与显示层：在「移动」模式下直接拖动态射的显示文字，不另画拖动圆点。标签文字及其透明命中区域始终叠放在后绘制的图形上方，避免被节点遮住或无法拖动；撤销／重做可恢复位置，Esc 取消正在进行的拖动。
  • 标签自动避让：新建态射的标签默认尝试避开图节点、其它箭头的实际绘制线段和普通文字对象。过密场景仍可能无法自动找到完全无遮挡的位置；手动拖动标签后会停止自动布局。
  • 界面调整：属性标题的「－」现在能正常折叠，按「＋」重新展开；数值从输入框左侧开始，右边保留上下微调箭头。暗色主题下导出按钮颜色更沉稳。射线端点、垂直平分线、直径圆、椭圆、闭合样条和态射图标重新核对了图形关系及圆点边界。
  • 选择「交换图节点」或「态射」时，自动开启网格吸附；切换到几何或其它工具时自动关闭。当前工具中可手动改动吸附开关，下次切换工具会恢复自动策略。这属于编辑器临时行为，不暗改项目 JSON。显示网格、吸附已有点和对象吸附分别独立设置。
  • 在「移动」模式中，直接拖动箭头上的文字／LaTeX 标签（如 \varphi）；无需拖单独的圆形手柄。撤销可恢复原位，Esc 可取消未完成的拖动，锁定态射不可拖动标签。
  • 箭头样式有实线、虚线、点线、钩形、虚线钩形、双箭头和尾部竖线；钩形箭尾采用类似 LaTeX 的开口括号形曲线，与箭杆切向平滑连接，而不是额外的小圆圈或突兀短钩。「箭头路径」支持直接连线、避让节点、减少交叉、所有箭头；拥挤的图仍可能需要手动调整，无法保证全局无交叉。
  • 「避让标签」「切换标签侧」两个复选框并列，字号一致；后一项切换标签所处箭头一侧，手动 X/Y 偏移保留。数值负号显示在前面（如 -36），右侧是微调箭头。新布局默认开启「仅基本工具」，需要高级工具可取消勾选。

界面和普通文字新增 Verdana、Trebuchet、Palatino、Times 等字体选项；LaTeX 继续使用内置数学字体。

几何工具扩充

默认启用「仅基本工具」，以保持工具面板简洁；取消勾选后显示全部工具。此开关只影响编辑器的按钮，不删除对象，也不修改项目 JSON。

  • 点与直线：「中点」跟随两个锚点，「射线」只向前延伸，「垂直平分线」始终垂直于两端点连线。
  • 过点平行线／过点垂线： 先取消勾选「仅基本工具」，选工具，再点一个已有点或画布空白处，最后点已有直线、线段、射线等。新直线经过指定点并随原直线方向动态变化。
  • 两圆交点： 取消“仅基本工具”，在“圆与圆锥曲线”中依次点击两个不同的圆。相交通常生成两个动态交点；相切生成一个；相离、内含或重合时不创建。修改定义圆的点后交点跟随变化；导致已有交点消失的移动会被拒绝。
  • 交点： 依次点击两条有唯一交点的直线类对象。线段只能在线段内部求交，射线只能向前求交；平行、重合或不相交时拒绝创建，不生成不可见点。另有「直线与圆交点」：依次点击一条直线类对象和一个圆（顺序不限），通常一次得到两个持续跟随的交点；相切只生成一个，线段与射线只保留位于其有效范围内的交点，完全不相交时不创建。暂不支持椭圆和一般曲线交点。
  • 持续依赖： 新构造使用对象 ID 引用。移动源锚点时交点自动更新；若移动会使原本有效的交点分支消失，则拒绝移动。删除源对象会同时删除依赖对象。按 Esc 或切换工具可取消未完成构造。
  • 圆与圆锥曲线：「直径圆」依次点击直径两端，并建立动态中点；「三点圆」由三个不共线点唯一确定，锚点移动时自动更新；椭圆仍使用两焦点及曲线上第三点。
  • 多边形：「三角形」三次点击完成，「四边形」四次点击完成；保存后它们都是普通可编辑多边形。「多边形」工具可持续添加顶点，按 Enter 完成。新建的多边形、三角形、四边形会同时生成每条独立线段，线段和多边形共享顶点，移动顶点时同步更新；删除多边形时连带删除这些线段。现在新建矩形会生成四条独立线段，新建正多边形会按边数生成对应的独立线段；这些线段的端点随定义点实时变化，可单独修改样式或删除。删除母图形会删除其剩余附属边。旧项目不自动补边。
  • 曲线：自由曲线、折线、贝塞尔、样条曲线与闭合样条归入同一组；贝塞尔曲线采用四个控制点。样条曲线依次经过至少三个点，按 Enter 完成；闭合样条首尾切线连续。交换图收录文字、图节点和态射。
  • 未完成构造按 Esc 或切换工具取消；切换为「仅基本工具」时，已有的高级几何对象不会隐藏。
  • 射线、垂直平分线、三点圆及样条曲线具有持续几何依赖关系，可保存为 JSON 或导出 SVG；不支持忠实表示时，TikZ 选项明确禁用，不会偷偷转换为其他图形。

命令输入

A = (0, 0)
B = (3, 2)
Segment(A, B)
Circle(A, B)
C = (1, 3)
Ellipse(A, B, C)
f(x) = sin(x) + x^2 / 4

乘法目前需要写明，例如 2*x。函数图像采用数值采样，可能漏掉奇点附近的细节；通用 3D 与参数滑块尚未实现。

交换图与 LaTeX

先创建「图节点」，再通过「态射」连接。新图节点及箭头标签默认用 LaTeX 排版，例如 \frac{A_1}{B_2}、\alpha\to\beta。在「属性 → 标签格式」中可切换数学公式与普通文字。用户填写的点标签与几何对象显示标签默认 LaTeX；自动生成的对象名称仍按普通文本显示，名称与标签彼此独立，旧项目原有文字模式保持不变。添加普通文字时，可以输入普通文本，也可用 $\alpha+\beta$ 包住 LaTeX，或直接输入以 \sqrt{x} 这样的 TeX 命令开头的表达式。创建后在属性的「标签格式」中也能切换；已保存的旧文字格式不会被自动覆盖。纯文本可选择字体。

图节点默认没有边框。箭头样式、弯曲程度及标签位置均可在属性中修改。导入 tikz-cd 后使用数学公式排版；不支持的宏会明确报错。

保存与导出

「保存」下载可编辑的 JSON。SVG 可包含数学公式的矢量字形，PNG/WebP/JPEG 为本地位图转换；JPEG 不支持透明背景。某些图形无法无损导出为 TikZ 或 tikz-cd，对应选项会停用。请定期下载 JSON 备份。

局限与参考

目前不是符号计算器、通用三维建模器或偏微分方程求解器。复杂图形可能仍需人工调整标签位置。可查看 技术文档 和 旧版详细手册（部分历史功能描述已过时）。

名称、标签与钩形箭头

  • 名称是唯一对象标识符，始终按普通文本显示；例如 Point_1 不会自动转为数学斜体。
  • 显示标签与名称互不混淆；用户输入的标签默认以 LaTeX 排版。清空显示标签便恢复普通文字名称；如需逐字显示可选择「标签格式 → 普通文本」。
  • 钩形／虚线钩形箭尾使用与箭杆平滑衔接的开口括号形曲线，不再生成游离弯钩。
  • 多选属性的「点大小」数字框与标题处于同一行；常用颜色以较柔和的「青色」替换原「天蓝色」。
