MathIllustrator

A local-first mathematical drawing editor. Your project remains editable in JSON; exporting an image does not replace that project.

Workspace

Objects and Properties stay docked on the left, with the canvas in the center and Tools on the right. None of these panels floats above the drawing. On desktop, drag the vertical dividers next to the canvas to resize Objects and Tools; focus a divider and use ←/→ (Shift for larger steps), Home/End, or double-click to reset. Drag the horizontal divider above Properties to change its height, or focus it and use ↑/↓, Home/End, or double-click to reset. Properties can be expanded or collapsed using its ± button, independent of the Objects list. Previously saved Float/Dock preferences are ignored; only dock widths/heights and collapsed states are retained in browser preferences, not project JSON. Mobile uses fixed left/right drawers, never floating overlays. Use the language control to switch English/Chinese; this tutorial follows the editor language and theme. In Settings you can change the UI font and Auto Pan / Move behavior. Tool groups and settings sections can be collapsed or reordered by dragging their handles or focusing a handle and pressing Alt+↑/↓.

Draw

Basic contains Move and Pan; Point and other constructions are under Geometry, grouped into Points & lines, Circles & conics, Polygons and Curves. Each subgroup can be independently collapsed and reordered by dragging its handle or pressing Alt+↑/↓. Diagrams is followed by Others (Free curve and Text). Choose Geometry tools and click the canvas. For a focal ellipse, click two distinct foci, then any third point away from the segment joining the foci. If that last click is close to an existing anchor on the focal segment, the editor keeps your actual clicked position rather than snapping it to an invalid ellipse; clicking exactly on the focal segment is still rejected. The two focus clicks can be close without collapsing to the same anchor. Existing two-corner ellipses in older projects still display. Move drags points; Pan shifts the view. In Move, Ctrl-click (or Cmd-click) and Shift-click on objects or list rows toggle extra selections; Ctrl-click also cycles overlapping canvas objects. Drag a selection rectangle from empty canvas: left-to-right includes fully enclosed visible objects, right-to-left includes touching ones. Hold Shift to add objects with a rectangle. Escape clears the selection or cancels an unfinished rectangle; a normal click replaces the selection. When several objects are selected, Properties edits their shared editable Stroke, Fill, Line width, Opacity and Point radius together in one undo step. Fill applies only to fill-capable types, point radius only to points, and locked objects are skipped; mixed numbers are blank until changed. Multi-selection is temporary and not saved to project JSON. Dragging a point does not move the entire multi-selection. When the Interface auto-mode checkbox is enabled (default), one completed construction returns to Pan, and dragging a movable object from Pan switches to Move. Disable it to retain the chosen tool. Wheel zooms. Polygon and Polyline end with Enter. Free curve joining magnetically attracts endpoints to nearby visible objects; the Open choice disables attachment and closure. New projects default to Ultra-smooth: arc-length resampling and Gaussian low-pass filtering reduce jitter; fewer samples keep the path responsive. A near-closed free curve uses a curved closing segment to avoid the old straight seam, while retaining a corner when entry and exit directions are distinct. Existing projects retain their explicitly saved smoothing mode. Geometry options organizes snapping controls under Snap and visibility controls under Show. Snap points to objects (on by default) attracts newly placed and moved points within 16 screen pixels of visible geometry; this saves the snapped coordinate, not a live dependency. Snap to grid and existing-point snapping remain separately adjustable. Recently Deleted lists original names and lets you restore removed objects. Choose New object style → Object naming to change names for future drawings; existing names stay unchanged. Pick common stroke/fill colors from the swatches in New object style or a selected object’s Properties; use the color picker for custom colors. The selected-object Properties and New object style use matching two-column color palettes (five swatches per row), with compact line-width, opacity and point-radius inputs beside their captions.

Controls and settings

All editor controls are intentionally short; this guide contains their detailed meanings. The book icon in the toolbar opens this tutorial. The status near the canvas names the active tool; no separate help bubble is required. Settings → Plotting → Plot detail: Fast prioritizes responsiveness, Balanced is the default, and Detailed samples more densely but can be slower; sampling can still miss narrow spikes, poles or rapid oscillations. Geometry options → Free curves: Open keeps a path open with no endpoint attraction; Join & snap joins nearby endpoints with a corner or smooth tangent and attracts both ends near other visible geometry. Off, Gentle, Medium, Strong and Ultra control curve smoothing/simplification; Ultra is the default for newly created projects, using lower-density resampling plus a Gaussian low-pass filter. Regular polygon sides sets the default number of vertices. Snap → Grid uses Snap interval, Points attracts to existing point anchors, and Objects attracts newly placed or moved points to visible geometry. Show → Grid, Axes, and Point labels control canvas overlays; label placement can be Standard or Avoid overlap. New object style includes stroke and fill color pickers and ten swatches (two rows of five), Width, Opacity, Point size and naming styles (PascalCase, camelCase and snake_case). Page & appearance includes Infinite/A4/Letter canvases. Image bounds sets which rectangle is exported: View exports everything visible in the drawing viewport, while Page crops to the A4/Letter page frame (on Infinite it behaves like View). Grid/axes in export includes whichever grid and axes are enabled under Show; when unchecked, these drawing guides are omitted from image exports. These controls affect SVG/PNG/JPEG/WebP images, not project JSON or TikZ coordinates. Raster resolution (1×–4×) multiplies pixel dimensions for PNG/JPEG/WebP; SVG remains vector. Theme (light/dark) changes the editor interface, while Background sets the drawing/image background. A transparent image background overrides the background color for SVG/PNG/WebP. Transparent exports support SVG, PNG and WebP, not JPEG. Interface → Auto Pan / Move enables both return to Pan after one construction and switch to Move on object drag. Rearrange sections with their grips, or focus a grip and use Alt+Up/Down.

In Properties, Name is the editable object identifier; names must be unique and nonempty. Referenced constructions follow their linked anchors. Freehand paths currently do not expose individual control vertices, and function samples have finite resolution. Text and arrow labels accept line breaks with Enter; click elsewhere to apply. For diagram arrows, choose Direct, Avoid nodes, Fewer crossings, or All arrows (the latter is limited to 48 arrows). These are best-effort screen-space routes, not a global guarantee; crossings and suppressed routes may remain, and bend is ignored when auto-routing. Arrow labels can be dragged by their visible handle in Move mode. Collision avoidance may fail for crowded labels, and manual positioning disables automatic placement. Auto label placement is not exported to TikZ. The Label position field accepts 0.05–0.95, Label distance and shift use CSS pixels. The contextual object icons mean Hide, Lock and Delete; hover or keyboard focus reveals their accessible labels. When locked, unlock via the object menu to edit. The tikz-cd importer accepts a supported environment and replaces the project only after confirmation. Export disables unavailable formats rather than silently changing their meaning.

Construction input

A = (0, 0)
B = (3, 2)
Segment(A, B)
Circle(A, B)
C = (1, 3)
Ellipse(A, B, C)
f(x) = sin(x) + x^2 / 4

Use explicit multiplication (2*x). Function plotting is approximate near discontinuities and narrow peaks. General 3D and parameter sliders are not yet available.

Diagrams & LaTeX

Choose a Diagram node, then a Morphism from source to target. Newly added diagram labels default to LaTeX math; use \frac{A_1}{B_2}, \alpha\to\beta, or \sqrt{x^2+y^2}. Set Label format in Properties to switch between mathematical typesetting and plain text. Point labels can also opt into LaTeX via Properties. The Text tool accepts ordinary plain text, or LaTeX typed as $\alpha+\beta$ or starting with a TeX command such as \sqrt{x}. In Properties, Label format switches Text, diagram nodes and morphisms between Plain text and LaTeX math; diagram nodes and morphisms default to LaTeX at creation, even with empty arrow labels. Existing saved text modes are never overwritten. Plain text retains the Font picker.

Diagram nodes have no border by default. Edit arrow style, curvature and label position in Properties. Imported tikz-cd labels use LaTeX. Complex macros outside the locally bundled math renderer are rejected rather than shown as correct mathematical output.

Save & export

Save downloads editable JSON. SVG uses embedded mathematical vector glyphs; PNG, WebP and JPEG are rasterized locally. Transparency is unavailable in JPEG. Restricted TikZ and tikz-cd exports are disabled for scenes they cannot faithfully represent. Browser storage is a convenience, not a substitute for project downloads.

Limits & documentation

This is not a symbolic algebra system, a general 3D modeller or a PDE solver. Mathematical spacing and collision avoidance may need manual adjustment. For original workflows, corner cases and technical verification, see technical documentation and extended historical guide (older feature descriptions may be obsolete).

MathIllustrator 快速指南

本地优先的数学绘图工具。项目可保存为可继续编辑的 JSON，不会将图像导出误认为项目备份。

界面

对象及属性始终停靠在左侧，中间为画布，工具始终停靠在右侧；三个面板都不再支持浮动覆盖画布。桌面端可拖动左右分隔线调整侧栏宽度，聚焦后用 ←/→（Shift 加速）、Home/End 或双击重置。属性始终停靠在对象列表下方，可通过上方横线拖动调整高度，也可聚焦后按 ↑/↓、Home/End 或双击恢复默认；属性标题右侧的 ± 用于展开或折叠。旧版保存的浮动状态不会再生效。宽度、高度及折叠状态仅存于当前浏览器，不写入项目 JSON。手机上左右两侧为抽屉，不存在浮动面板。顶部语言按钮切换中英文，教程自动跟随编辑器语言及主题。右侧「设置」可调整字体与自动平移／移动；工具组和设置分区可折叠，并可拖动把手或聚焦后按 Alt+↑/↓ 调整顺序。

绘图

「基本」包括移动和平移；点和其他几何工具位于「几何」，并分成「点与直线」「圆与圆锥曲线」「多边形」「曲线」四组。各组可单独折叠，拖动组旁把手或按 Alt+↑/↓ 调整各组顺序。交换图之后的「其他」包含自由曲线和文字。选择几何工具后点击画布。画椭圆时先点两个不同的焦点，再点不位于焦点连线线段上的第三点。若第三次点击靠近焦点线段上的已有点，程序不会把有效点击错误吸附为退化椭圆；实际点击正好落在焦点线段上仍会被拒绝。相邻但不同的两个焦点不再被强制合并；旧项目的两角点椭圆继续兼容。移动工具可拖动点；平移工具移动视图。在移动模式中，可使用 Ctrl／Cmd 或 Shift 单击画布对象或对象列表行来增减多选；Ctrl 单击还能轮换重叠对象。从画布空白处拖出选框：从左向右只选择完全包含的可见对象，从右向左选中与选框相交的对象；按 Shift 拖框可增选。按 Esc 清除选中项或取消未完成的框选，普通单击替换选中项。多选后可在属性面板一次性编辑支持的线条色、填充色、线宽、不透明度和点半径，每次修改只有一条撤销记录。填充只作用于可填充对象，点半径只作用于点，锁定对象不参与修改；不同的数字值显示为空直至输入新值。多选仅保存在当前编辑器，不写入项目 JSON。拖动某个点不会整体移动全部选中对象。默认勾选的自动模式会在完成一次构造后返回平移模式，在平移模式中拖动对象则切换为移动模式；取消勾选可保持当前工具。滚轮缩放。多边形及折线按 Enter 完成。自由曲线启用连接时，首尾靠近可见对象会自动吸附，选择保持开放则禁用吸附和闭合；新项目默认「超平滑」，以等弧长降采样和高斯数值滤波减小抖动，降低采样点密度以兼顾速度；旧项目保留已存的平滑选项。自动闭合的短间隙使用弯曲连接，而不是明显的直线段；在非切向端点处仍保留必要的折角。「几何选项」将复选框按「吸附」和「显示」分组；默认开启「点吸附到附近对象」，新建或移动点靠近可见曲线时以 16 屏幕像素为阈值吸附到曲线，保存坐标但不建立持续依赖；网格和已有点吸附仍可分别设置。「最近删除」显示对象原名，并支持恢复。在「新对象样式 → 对象命名」可设置新建对象的命名方式，已有名称不会改变。可在「新对象样式」或选中对象的「属性」中直接点击常用线条／填充色；自定义颜色仍可通过颜色选择器设置。新对象样式与属性编辑均采用一致的双列颜色区，每种颜色两排、每排五个色块；线宽、不透明度、点半径的小输入框都位于标签右边。

控制与设置说明

编辑器中使用简短的标签，详细含义集中在本教程。顶部书本图标打开教程；画布上方显示当前工具名称。「绘图 → 绘图精度」的快速强调速度，均衡是默认值，精细采用更多采样点但仍可能漏掉极窄尖峰、极点或快速振荡。「几何选项 → 自由曲线」的开放不连接首尾也不吸附；连接并吸附会在端点足够接近时连接（切线近似平滑，否则保留尖角），还会吸附到附近可见几何对象。「曲线平滑」可选关闭、轻度、中度、强、超平滑，新建项目默认超平滑并进行较低密度的等弧长采样及高斯滤波。「正多边形边数」调整新建多边形的默认边数。「吸附」中的网格使用设定间隔，点吸附已有锚点，对象吸附可见几何图形；「显示」中的网格、坐标轴、点标签决定画布显示内容，标签布局可选标准或避免重叠。「新对象样式」包含线条与填充颜色选择器、各十个常用色块（每排五个）、线宽、不透明度、点大小，以及大驼峰／小驼峰／下划线式命名。「画布与外观」中，图像范围的「视图」导出当前看到的画布；「页面」仅导出 A4/Letter 纸张边框内的区域（无限画布时与「视图」相同）。导出网格／坐标轴勾选时会在图像中包含「显示」里已开启的网格和坐标轴；不勾选时图像不带这些辅助线，项目 JSON 不受影响。位图分辨率 1×–4× 仅改变 PNG/JPEG/WebP 像素数，SVG 为矢量图。主题控制编辑器界面的明暗，背景色决定画布及图像底色，勾选透明背景可在支持的图像格式中覆盖背景色。SVG/PNG/WebP 可透明，JPEG 不可。「界面 → 自动平移／移动」控制构造完成后自动返回平移，以及在平移模式拖动对象时切换移动。拖动分区把手调整顺序，聚焦后可按 Alt+↑/↓。

「属性 → 名称」是对象的唯一可编辑名称，不能为空或重复；有引用关系的构造随其锚点变化。自由曲线暂不支持逐点编辑，函数采样存在有限分辨率。文本及箭头标签可按 Enter 插入换行，点击外部提交。态射路径可选直接连线、避让节点、减少交叉、所有箭头（最多处理 48 支）；这些都是尽力处理屏幕空间中的交叉，不能保证完全无交叉，自动布线时不使用手动弯曲数值。在移动模式可以拖动箭头标签手柄；拥挤时标签避让可能失败，手动移动后会转为手动布局，自动位置也不能完整导出到 TikZ。标签位置范围 0.05–0.95，距离与偏移以像素计。对象菜单的眼睛、锁及垃圾桶分别代表隐藏、锁定、删除，鼠标悬停或键盘聚焦可查看名称。对象锁定后需先解锁才能编辑。导入 tikz-cd 时粘贴受支持的环境，确认后才替换当前项目；不可导出的格式会停用。

命令输入

A = (0, 0)
B = (3, 2)
Segment(A, B)
Circle(A, B)
C = (1, 3)
Ellipse(A, B, C)
f(x) = sin(x) + x^2 / 4

乘法目前需要写明，例如 2*x。函数图像采用数值采样，可能漏掉奇点附近的细节；通用 3D 与参数滑块尚未实现。

交换图与 LaTeX

先创建「图节点」，再通过「态射」连接。新图节点及箭头标签默认用 LaTeX 排版，例如 \frac{A_1}{B_2}、\alpha\to\beta。在「属性 → 标签格式」中可切换数学公式与普通文字。点标签也可自行启用 LaTeX。添加普通文字时，可以输入普通文本，也可用 $\alpha+\beta$ 包住 LaTeX，或直接输入以 \sqrt{x} 这样的 TeX 命令开头的表达式。创建后在属性的「标签格式」中也能切换；已保存的旧文字格式不会被自动覆盖。纯文本可选择字体。

图节点默认没有边框。箭头样式、弯曲程度及标签位置均可在属性中修改。导入 tikz-cd 后使用数学公式排版；不支持的宏会明确报错。

保存与导出

「保存」下载可编辑的 JSON。SVG 可包含数学公式的矢量字形，PNG/WebP/JPEG 为本地位图转换；JPEG 不支持透明背景。某些图形无法无损导出为 TikZ 或 tikz-cd，对应选项会停用。请定期下载 JSON 备份。

局限与参考

目前不是符号计算器、通用三维建模器或偏微分方程求解器。复杂图形可能仍需人工调整标签位置。可查看 技术文档 和 旧版详细手册（部分历史功能描述已过时）。
